# Олимпиадная база

Открытая база для подготовки к олимпиадам по программированию: статьи (Теория), подборки задач (Практика) и страница прогресса по хендлу Codeforces.

Каждая статья начинается с задачи, которую тема делает простой, написана понятно для школьника и проверена олимпиадником.

## Запуск

Windows:

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m mkdocs serve
```

macOS и Linux:

```
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m mkdocs serve
```

Сайт откроется на http://127.0.0.1:8000.

## Статистика

На странице «Статистика» введи хендл Codeforces. Сайт учитывает все полученные решённые задачи, текущий рейтинг и сложность последних решений, предлагает нерешённые задачи подходящего уровня. Отметки «теория изучена» сохраняются в браузере отдельно для каждого хендла и влияют на рекомендации, но не на число решений.

Каталог рекомендаций собирается из `data/cf_problems.json`; при отсутствии кэша его скачивает `scripts/check.py`. После обновления кэша, статей или подборок пересобери каталог, чтобы обновились задачи и готовность статей:

```
python scripts/build_progress_catalog.py
```

Источники задач хранятся в `data/practice_sources.json`. Проверка подписей без сети — `python scripts/update_practice_sources.py --check`; обновление по официальным названиям соревнований — `python scripts/update_practice_sources.py --refresh`. Оценки AtCoder со знаком «≈» — приблизительный перевод в шкалу CF, не официальный рейтинг.

## Генератор тренировочных задач

В разделе «Практика» доступны шесть схем: бинарный поиск, префиксные суммы, два указателя, жадные алгоритмы, ДП и кратчайшие пути. AITUNNEL создаёт название и сюжет; формальные условия, примеры, ожидаемые ответы и тесты формирует проверенный код. Это вариации шести схем, а не свободная генерация произвольных олимпиадных задач. Сгенерированный код не выполняется.

Настройка на Windows (ключ вводится скрыто и сохраняется в игнорируемом `.env`):

```
.venv\Scripts\python.exe scripts\configure_generator.py
.venv\Scripts\python.exe -m mkdocs build --strict
.venv\Scripts\python.exe scripts\serve_generator.py
```

Полный сайт с генератором откроется на `http://127.0.0.1:8002/practice/`. Генератор также доступен из `mkdocs serve` на портах 8000 и 8001. Ключ перечитывается без перезапуска; после изменения Python-кода сервер нужно перезапустить.

Настройки сервера: `GEN_API_KEY`, `GEN_MODEL` (по умолчанию `gpt-4.1-mini`), `GEN_BASE_URL` (по умолчанию `https://api.aitunnel.ru/v1`), `GEN_ALLOWED_ORIGINS` (разрешённые адреса сайтов через запятую). Ключ не попадает в HTML/JS и не должен добавляться в Git. Модель не переключается автоматически, при ошибке API показывается сообщение.

Для публичного сайта нужен запущенный Python-сервер за HTTPS. Он может раздавать `site/` и API вместе, либо адрес API задаётся в `docs/assets/generator.json`, а домен сайта добавляется в `GEN_ALLOWED_ORIGINS`. Одна статическая публикация не запускает Python API. `--host` и `--port` задают адрес сервера. Ограничения процесса: две одновременные генерации, пять запросов в минуту с одного IP и сто в час суммарно.

Проверка алгоритмов, API и обработки ошибок:

```
.venv\Scripts\python.exe scripts\test_generator.py
```

## ИИ-наставник

Кнопка «Спросить ИИ» доступна на любой странице. Можно попросить одну подсказку, объяснение или логическую проверку своей идеи/кода. Выдели фрагмент статьи перед открытием, чтобы обсудить именно его. У сгенерированной задачи есть отдельная кнопка «Обсудить задачу с ИИ».

Наставник работает через тот же сервер и ключ AITUNNEL: `POST /api/mentor`. Модель получает вопрос, выбранный фрагмент, контекст текущей страницы и последние сообщения разговора. История хранится только в памяти вкладки и сбрасывается при переходе на другую страницу. Код ученика не запускается, ответ ИИ не является вердиктом тестирующей системы.

По номеру, названию или теме наставник ищет карточки во всём `data/problems.csv` и фрагменты готовых статей. Материалы перечитываются при запросе, поэтому новые задачи и статьи доступны после обновления репозитория без отдельной загрузки в модель. Карточка внешней задачи содержит метаданные и подсказки, но не полное условие: наставник должен попросить недостающий текст, если без него нельзя ответить. На явный запрос первой подсказки известной задачи выдаётся текст из базы без перегенерации. Для последующих объяснений модель получает опорные материалы решения, но в режиме подсказки должна раскрывать только один шаг. Ссылки на найденные материалы показываются под ответом.

Адрес API задаётся полем `mentor_endpoint` в `docs/assets/generator.json`. Для отдельного домена API также нужен `GEN_ALLOWED_ORIGINS`. Проверки: `.venv\Scripts\python.exe scripts\test_mentor.py`.

## Архив олимпиад

В «Практике» есть переход в архив: олимпиада → сезон → условия, задачи и местные разборы. Восемь задач финала ВсОШ 2025–2026 также включены в тематические подборки и каталог рекомендаций. Их сложность помечена знаком «≈» как оценка ИИ; она не подменяет официальный рейтинг. Решённая Gym-задача засчитывается, если присутствует в ответе Codeforces и относится к подборке. Разборы сохраняют исходную отметку о необходимости человеческой вычитки.

Исходники архива остаются в `data/olympiads/`. После их изменения запусти `python scripts/sync_olympiad_archive.py`: скрипт создаёт страницы в `docs/practice/olympiads/` и переводит внутренние ссылки на адреса сайта. `--check` проверяет синхронизацию без записи. Опубликованные копии не редактируют вручную; внешние PDF и условия не копируются.

Наставник умеет читать опубликованный разбор, искать Gym-задачу по ссылке или обозначению `106582/1` и давать ссылку на разбор внутри сайта.

## Как добавить статью или задачу

1. Сделай форк репозитория и отдельную ветку.
2. Статья — `docs/theory/<тема>.md` строго по стандарту `docs/STYLE.md`; подборка задач — `docs/practice/<тема>.md`.
3. Запусти `python scripts/check.py` — должно быть GREEN: ссылки на Codeforces сверяются с официальным API.
4. Открой pull request. Статью проверяет олимпиадник и ставит подпись «Проверил».
