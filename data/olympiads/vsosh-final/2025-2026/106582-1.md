## Условие кратко

Есть $n$ серверов, на $i$-м работает $a_i$ служб. У каждого сервера есть резервный $p_i$, массив $p$ — перестановка; если $p_i = i$, сервер надёжный и никогда не отключается. При отключении сервера $i$ все его службы переезжают на $p_i$, а сам сервер остаётся пустым. Можно отключить не больше $k$ серверов по очереди. Найти наибольшее число служб, которые могут оказаться на одном сервере.

## Идея

Рёбра $i \to p_i$ перестановки разбивают серверы на независимые циклы: службы никогда не уходят из своего цикла. Отключение сервера «вливает» его службы в следующий по циклу. Поэтому за $t \le k$ отключений на одном сервере можно собрать только службы $t+1$ подряд идущих серверов цикла.

## Решение

1. Разложи перестановку на циклы обходом с массивом `used`.
2. Для цикла длины $m$ выпиши $b_0, \dots, b_{m-1}$ в порядке рёбер. Ответ для него — максимальная сумма на циклическом подотрезке длины не больше $L = \min(m, k+1)$.
3. Все $a_i \ge 0$, поэтому удлинять отрезок не вредно: достаточно окон длины ровно $L$. Удвой массив и пройди скользящим окном.
4. Ответ — максимум по всем циклам. Надёжный сервер — это цикл длины 1, для него ответ $a_i$.

## Сложность

$O(n)$ времени и памяти: суммарная длина циклов равна $n$.

## Подзадачи из разбора

- $k = 1$: ответ — максимум из $\max a_j$ и $a_i + a_{p_i}$ по всем $i$ с $p_i \ne i$.
- $n \le 1000$: в каждом цикле перебрать начало и длину отрезка, $O(n^2)$.
- Один цикл $p_i = i \bmod n + 1$: сразу скользящее окно.
