Пересказ официального разбора. Черновик ИИ, олимпиадником не проверен.

## Условие кратко

$n \le 2 \cdot 10^6$ предметов, у $i$-го есть «странность» $w_i < 2^k$ ($k \le 22$) и стоимость $c_i$. Для каждого префикса $1..i$ нужно выбрать набор со стоимостью не меньше $C$ и минимальным побитовым OR странностей. Если такого набора нет, ответ $-1$.

## Идея

Если OR должен быть подмаской $x$, выгодно взять **все** предметы с $w_j \subseteq x$. Поэтому ответ для префикса $i$ — минимальная маска $x$, для которой
$F_i(x) = \sum_{j \le i,\ w_j \subseteq x} c_j \ge C$.

С ростом $i$ ответ не увеличивается. Маску можно строить жадно от старшего бита: ставим очередной бит в 0, если даже при всех единицах в младших битах стоимости хватает.

## Решение

1. Сначала найди первый префикс, у которого сумма всех $c$ дошла до $C$. Все префиксы до него дают $-1$.
2. Запусти рекурсию `solve(pref, [L, R], cnt, t)`:
   - `pref` — уже выбранные старшие биты ответа, общие для всех префиксов из $[L, R]$;
   - `cnt[s]` для $s < 2^t$ — суммарная стоимость предметов из первых $L-1$, которые не противоречат `pref` и у которых младшие $t$ бит равны $s$.
3. Решаем старший из оставшихся бит. Если он 0, можно брать только нижнюю половину `cnt`. Проходим предметы $L, L+1, \dots$ и находим первую позицию $M$, где сумма нижней половины дошла до $C$. Для префиксов $[L, M-1]$ бит равен 1, для $[M, R]$ — 0.
4. Рекурсия в левую часть получает $next_1[s] = cnt[s] + cnt[s + 2^{t-1}]$. Рекурсия в правую — нижнюю половину, дополненную предметами $L..M-1$; её набираем во время поиска $M$.

## Сложность

$O(nk + 2^k k)$.

## Подзадачи из разбора

- $k \le 10$: поддерживать $F_i(x)$ напрямую, $O(n \cdot 2^k)$.
- $w_i$ — степени двойки: жадность по битам за $O(nk)$ с вычитанием сумм.
- $k \le 16$: meet-in-the-middle — делим маску на старшую и младшую половины.
