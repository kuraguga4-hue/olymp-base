## Как устроена папка сезона

- `README.md` — официальные материалы (условия, разбор, архив жюри) и таблица задач, которые можно сдать на Codeforces.
- `<контест>-<задача>.md` — наш разбор одной задачи. Это пересказ официального разбора: идея, решение, сложность, подзадачи. Если официального разбора нет, разбор написан самостоятельно, и это сказано в начале файла.
- Задачи с Codeforces, к которым есть наш разбор, добавлены в общую таблицу [`data/problems.csv`](../problems.csv) с темами и подсказками. В столбце «Разбор» там указан путь к файлу разбора.

## Что сделано и что нет (25.10.2026)

- Собраны найденные материалы 104 сезонов шести олимпиад. Полнота исторических архивов не подтверждена; недоступные и ненайденные материалы пропущены.
- В списках 603 уникальные задачи Codeforces. Обработка четырёх задач Vorg CUP пропущена из-за недоступности условий; найденные ссылки сохранены для справки.
- Для 8 из остальных 599 задач подготовлены отдельные разборы и строки в `data/problems.csv`: финал ВсОШ 2025-2026. Разборы и подсказки сверены вторым агентом с официальными текстами; человеческой вычитки и проверки программ решений пока нет.
- Ещё 591 задача не обработана: её нет в общей таблице, отдельный разбор и подсказки не подготовлены. Самостоятельных разборов для задач без официального решения пока нет.
- Тренировка Codeforces 102147 (ВсОШ 2018, 1 тур) закрыта для API, поэтому её задач в таблице нет.
- Сайт inf-open.ru (Открытка с 2023-2024) 25.10.2026 не открывался (502). Для этих лет есть только задачи на Codeforces.
- Vorg CUP: условия найдены только на Codeforces, а страницы Codeforces были недоступны для скачивания. Эти задачи пропущены; разборов, подсказок и строк в общей таблице для них нет.

Списки задач тренировок собраны через Codeforces API (`contest.status`: буквы и названия задач из публичных посылок).
