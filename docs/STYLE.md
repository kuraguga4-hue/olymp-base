# Стандарт статьи

**Читатель:** школьник 8–11 класса, знает базовый C++ или Python, циклы и массивы; тему видит впервые. Чтение — 10–15 минут.

**Шапка статьи:** уровень · время чтения · теги · «Проверил: —» (заполняет человек).

## Разделы — строго в этом порядке

1. **Зачем это нужно.** 3–6 строк. Красивая задача (поле hook в `docs/assets/topics.json`), которая без этой темы решается медленно или некрасиво, а с ней — просто. На числах.
2. **Идея на пальцах.** Интуиция на маленьком примере с числами, до формул. Таблица или схема, если помогает.
3. **Алгоритм.** Шаги по порядку. Сложность по времени и памяти — и откуда она берётся.
4. **Код.** C++ и Python во вкладках, 10–40 строк, комментарии только к неочевидным строкам. Код запускался на примере из раздела 2.
5. **Решаем задачу из раздела 1.** Как тема её упрощает — по шагам.
6. **Типичные ошибки.** 3–5 пунктов: что ломается и как это заметить (границы, переполнение, пустой ввод, off-by-one).
7. **Практика.** 3 задачи по возрастанию из `docs/practice/<slug>.md` + ссылка на всю подборку.
8. **Куда дальше.** 2–4 ссылки (cp-algorithms, Algorithmica, блоги Codeforces) — к каждой одна фраза, что там.

## Язык

- Коротко, по-человечески, на «ты». Термин сначала объяснить, потом использовать.
- Без воды: никаких «важно отметить», «в современном мире», «таким образом», «давайте разберёмся».
- Каждое утверждение проверяемо. Не уверен — не пиши.
- Формулы — KaTeX, но сначала на числах.

## Самопроверка агента перед сдачей

- [ ] Разделы 1–8 на месте и в этом порядке.
- [ ] Пример из раздела 2 посчитан вручную и верен.
- [ ] Оба кода запущены на примере, вывод совпал — вывод в отчёте.
- [ ] Сложность в разделе 3 совпадает с кодом.
- [ ] `python scripts/check.py` — GREEN.
- [ ] Нет фраз из списка «вода».
