## Как работаем с ИИ
- Claude Code в VS Code на всех ноутбуках; общий контекст — файлы репозитория (`AGENTS.md`, `CLAUDE.md`, `docs/`).
- Конвейер статьи: агент пишет по `STYLE.md` и эталону → сам запускает код и `check.py` → Иван читает как новичок → Саша или Кирилл вычитывают новой сессией-редактором → агент вносит только подтверждённые правки → «Проверил» → push.
- Ошибки ИИ → `docs/INCIDENTS.md` → при повторе новое правило в `AGENTS.md`. Это рассказ для критерия «использование ИИ».
- Экономия: одна задача — одна сессия; контекст файлами; правки точечные; без субагентов.
