## Подсказки

??? question "1. 1360B · Честный тренер"

    ??? tip "Подсказка 1"
        Какую наименьшую разность может иметь ответ и какие два спортсмена её дают?

    ??? tip "Подсказка 2"
        Отсортируй спортсменов по силе: пара с минимальной разностью стоит на соседних позициях, и меньше ответа получить нельзя. Раздели массив по этой границе: всех, кто стоит в отсортированном порядке не правее первого из пары, отправь в первую команду, остальных во вторую. Ответ равен минимальной разности соседних.

    [Официальный разбор](https://codeforces.com/blog/entry/77846)

??? question "2. 1399A · Удалить наименьшее"

    ??? tip "Подсказка 1"
        В каком порядке выгодно удалять элементы и что мешает удалить какой-то из них?

    ??? tip "Подсказка 2"
        Отсортируй массив и удаляй от меньшего к большему. Если для какого-то $i$ выполнено $a_i-a_{i-1}>1$, то $a_{i-1}$ удалить нельзя и ответ NO, иначе YES.

    [Официальный разбор](https://codeforces.com/blog/entry/81082)

??? question "3. 1742B · Возрастающий"

    ??? tip "Подсказка 1"
        Когда массив нельзя переставить так, чтобы он строго возрастал?

    ??? tip "Подсказка 2"
        Если есть два равных элемента, ответ NO, потому что ни один не меньше другого. Иначе ответ YES: достаточно отсортировать массив.

    [Официальный разбор](https://codeforces.com/blog/entry/107962)

??? question "4. 1760A · По середине"

    ??? tip "Подсказка 1"
        Какой элемент окажется посередине, если расположить три числа по порядку?

    ??? tip "Подсказка 2"
        Отсортируй три числа и выведи среднее.

    [Официальный разбор](https://codeforces.com/blog/entry/109348)

??? question "5. 2238A · Очередная головоломка от Папируса"

    ??? tip "Подсказка 1"
        Если разрешено переставлять элементы $a$, как проверить, что можно добиться $a_i \ge b_i$ для всех $i$?

    ??? tip "Подсказка 2"
        Отсортируй оба массива и сравни поэлементно: если где-то $a_i < b_i$, ответ $-1$. Число вычитаний всегда равно $S=\sum (a_i-b_i)$, а если в исходном порядке есть $a_i < b_i$, добавь стоимость перестановки $c$.

    [Официальный разбор](https://codeforces.com/blog/entry/154829)

??? question "6. 1850D · Сбалансированный раунд"

    ??? tip "Подсказка 1"
        Как должны стоять задачи, чтобы разности соседних были как можно меньше, и какие задачи тогда остаются в раунде?

    ??? tip "Подсказка 2"
        Отсортируй сложности: оставляемые задачи образуют подотрезок, где каждая соседняя разность не больше $k$. Найди самую длинную такую цепочку одним проходом, сбрасывая счётчик в 1 при разности больше $k$; ответ равен $n$ минус длина этой цепочки.

    [Официальный разбор](https://codeforces.com/blog/entry/118466)

??? question "7. 1808B · Игра в казино"

    ??? tip "Подсказка 1"
        Можно ли решать задачу независимо для каждого столбца?

    ??? tip "Подсказка 2"
        Да, ответ для столбца — сумма $|a_i-a_j|$ по всем парам. Отсортируй столбец: вклад $i$-го элемента равен $a_i\cdot i - sum$, где $sum$ — сумма на префиксе, поэтому раскрывать модуль легко.

    [Официальный разбор](https://codeforces.com/blog/entry/114523)

??? question "8. 1918E · ace5 и порядок задач"

    ??? tip "Подсказка 1"
        Как сравнить загаданный элемент с другим, если запрос меняет значение $x$ и его нужно возвращать обратно?

    ??? tip "Подсказка 2"
        Выбери случайный индекс $i$ и делай запрос $? i$, пока не получишь ответ $=$, то есть $x = a_i$.

    ??? tip "Подсказка 3"
        Затем спрашивай про все остальные элементы, определяя, больше они $a_i$ или меньше (после каждого запроса возвращай $x = a_i$). Разбей элементы на две части и запусти алгоритм рекурсивно, как быструю сортировку.

    ??? tip "Подсказка 4"
        Есть и нерандомизированный вариант: найди элементы $1$ и $n$ за $3n$ запросов каждый, и тогда можно брать $x = n/2$ вместо случайного. Оба решения укладываются в $40n$ запросов.

    [Официальный разбор](https://codeforces.com/blog/entry/125300)
