## Подсказки

??? question "1. 2225C · Красно-чёрные пары"

    ??? tip "Подсказка 1"
        Каждая пара — это доминошка. Как может выглядеть покрытие доски $2 \times n$ доминошками, если смотреть с первого столбца?

    ??? tip "Подсказка 2"
        Покрытие состоит из вертикальных доминошек и пар горизонтальных, занимающих два столбца. Пусть $dp[i]$ — минимум перекрашиваний в первых $i$ столбцах: переходы $dp[i+1]=dp[i]+cost\_vertical(i)$ и $dp[i+2]=dp[i]+cost\_horizontal(i)$, ответ $dp[n]$ за $O(n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/153154)

??? question "2. 2274B · Префикс"

    ??? tip "Подсказка 1"
        Если зафиксировать позицию $j$, от чего зависит максимальное итоговое значение в ней и какие префиксные суммы тебе тогда нужны?

    ??? tip "Подсказка 2"
        Поддерживай наименьшую $L$ и наибольшую $H$ достижимые префиксные суммы: $L \leftarrow \min(a_i, a_i+2L)$, $H \leftarrow \max(a_i, a_i+2H)$ (средний вариант можно не рассматривать). Ответ — максимум по всем $i$ из $\max(a_i+H, a_i-L)$, за $O(n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/157634)

??? question "3. 1350B · Орак и модели"

    ??? tip "Подсказка 1"
        Какой должна быть последняя модель в красивой последовательности и какая у неё может быть предыдущая?

    ??? tip "Подсказка 2"
        Пусть $f_i$ — длина самой длинной красивой последовательности, заканчивающейся индексом $i$.

    ??? tip "Подсказка 3"
        Предыдущий индекс $j$ обязан быть делителем $i$ с $s_j < s_i$, поэтому $f_i$ — максимум $f_j+1$ по таким $j$.

    ??? tip "Подсказка 4"
        Можно перебирать кратные каждого индекса за $O(n \log n)$ или делители за $O(n\sqrt n)$; ответ — максимум $f_i$.

    [Официальный разбор](https://codeforces.com/blog/entry/77284)

??? question "4. 698A · Каникулы"

    ??? tip "Подсказка 1"
        Что нужно знать про предыдущий день, чтобы решить, чем заниматься сегодня?

    ??? tip "Подсказка 2"
        Удобно искать максимальное число дней, когда Вася не отдыхает, и вычесть его из $n$.

    ??? tip "Подсказка 3"
        Состояние: $d[i][j]$, где $j$ — занятие в день $i$ (0 — отдых, 1 — контест, 2 — спортзал). Отдых можно ставить после любого состояния предыдущего дня, контест — после отдыха или спортзала, спортзал — после отдыха или контеста, если они доступны в этот день.

    ??? tip "Подсказка 4"
        Ответ — $n$ минус максимум по $d[n][j]$; работает за $O(n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/46148)

??? question "5. 2070D · Прыжки по дереву"

    ??? tip "Подсказка 1"
        Что должно быть верно про предыдущую вершину $u$ в последовательности относительно вершины $v$?

    ??? tip "Подсказка 2"
        Пусть $dp_v$ — число допустимых последовательностей, заканчивающихся в $v$. Предыдущая вершина $u$ лежит на глубине на $1$ меньше и не является родителем $v$.

    ??? tip "Подсказка 3"
        Прямая сумма по всем таким $u$ слишком медленная. Храни $tot_i$ — сумму $dp$ по всем вершинам на глубине $i$.

    ??? tip "Подсказка 4"
        Тогда $dp_v=tot_{d_v-1}-dp_{p_v}$ (для корня вычитаем $0$). Вершины обрабатывай по возрастанию глубины. Ответ — сумма всех $dp_v$.

    [Официальный разбор](https://codeforces.com/blog/entry/140118)

??? question "6. 2184F · Вишнёвое дерево"

    ??? tip "Подсказка 1"
        От какой величины зависит, получится ли общее число вершин, за которые трясут, кратным $3$, если считать по поддеревьям?

    ??? tip "Подсказка 2"
        Заведи $dp[u][i]$: можно ли собрать всю вишню в поддереве $u$, если количество вершин, за которые потрясли в поддереве, даёт остаток $i$ по модулю $3$.

    ??? tip "Подсказка 3"
        Для листа истинно только $dp[u][1]$. Для нелистовой $u$ есть два случая: $u$ не трясли, тогда по детям поочерёдно объединяешь остатки по формуле $k=(i+j)\bmod 3$, или трясли $u$, тогда в поддереве больше никого не трясли и получаешь $dp[u][1]=$ True.

    ??? tip "Подсказка 4"
        Ответ лежит в $dp[1][0]$. Есть и аналитический вариант: ответ «нет» только если все вершины с ненулевым $(c-1)\bmod 3$ ($c$ число детей) лежат на одном пути до корня и их значения чередуются $1,2,1,2,\ldots$, это проверяется одним DFS.

    [Официальный разбор](https://codeforces.com/blog/entry/150033)

??? question "7. 2252E · Генерация троек"

    ??? tip "Подсказка 1"
        Как условие арифметической прогрессии вместе с XOR, равным нулю, связывает $a$ и $c$?

    ??? tip "Подсказка 2"
        Из $2b=a+c$ и $b=a\oplus c$ получаем $a\oplus c=2(a\,\&\,c)$, используя $a+c=(a\oplus c)+2(a\,\&\,c)$. Значение $b=a\oplus c$ определено однозначно.

    ??? tip "Подсказка 3"
        Осталось посчитать пары $a<c\le n$ с условием $a\oplus c=2(a\,\&\,c)$.

    ??? tip "Подсказка 4"
        Это цифровая динамика по битам от $60$ до $0$ с состоянием $(\text{bit},\text{c\_less},\text{a\_less},\text{need})$.

    ??? tip "Подсказка 5"
        Флаг $\text{need}$ говорит, каким должен быть бит $a\,\&\,c$; следующее значение $\text{need}$ равно XOR текущих битов $a$ и $c$. На бите $-1$ возвращаем $1$, если $\text{need}=0$ и $a<c$. Итого $O(\log n)$ на тест.

    [Официальный разбор](https://codeforces.com/blog/entry/155741)

??? question "8. 2245F · Знакомо?"

    ??? tip "Подсказка 1"
        Что происходит с монотонным стеком, когда в него попадает минимум отрезка?

    ??? tip "Подсказка 2"
        Минимум $p_k$ вытесняет всё оставшееся от левой части и остаётся на дне стека, поэтому делит отрезок на две независимые части.

    ??? tip "Подсказка 3"
        Это подсказывает ДП по отрезкам: $f_{l,r,c}$ — число способов выбрать относительные значения на $[l,r]$ так, чтобы выполнялись все $a_i$ и после обработки в стеке осталось ровно $c$ элементов.

    ??? tip "Подсказка 4"
        Переход перебирает позицию минимума $k$: $f_{l,r,c}=\sum_k\binom{r-l}{k-l}W(l,k)f_{k+1,r,c-1}$, где $W$ равно $f_{l,k-1,a_k}$ при известном $a_k$ и сумме по всем $c$ при $a_k=-1$.

    ??? tip "Подсказка 5"
        Введи $g_{l,r}=\sum_c f_{l,r,c}$, а $f$ считай только до нужных $c\le a_{r+1}$: каждый элемент стека выталкивается не более одного раза, поэтому сумма $a$ не превышает $n$. Получается $O(n^3)$.

    [Официальный разбор](https://codeforces.com/blog/entry/155232)
