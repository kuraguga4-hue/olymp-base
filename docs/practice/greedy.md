## Подсказки

??? question "1. 1992A · Одни плюсы"

    ??? tip "Подсказка 1"
        К какому из трёх чисел выгодно прибавлять единицу, чтобы произведение выросло сильнее всего?

    ??? tip "Подсказка 2"
        К наименьшему: приращение произведения равно произведению двух остальных. Пять раз найди минимум и прибавь к нему единицу, $O(1)$.

    [Официальный разбор](https://codeforces.com/blog/entry/131461)

??? question "2. 2267A · Превратить в палиндром"

    ??? tip "Подсказка 1"
        Что нужно сделать с каждой парой символов $s_i$ и $s_{n-i+1}$, чтобы строка стала палиндромом, и зависят ли пары друг от друга?

    ??? tip "Подсказка 2"
        Рассмотри пары отдельно: равные символы не трогаем, если один из них уже равен $c$, меняем другой за одну монету, иначе меняем оба за две. Сложи затраты по парам, $O(n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/157126)

??? question "3. 2245B · Удалить и сконкатенировать"

    ??? tip "Подсказка 1"
        Чему равен итог при $c=0$: суммой какого подмножества элементов он может быть?

    ??? tip "Подсказка 2"
        Пусть $m=\lceil n/2\rceil$. При $c=0$ достижима сумма $k$ наибольших элементов для любого $k$ от $m$ до $n$, поэтому берём $\max(m,p)$ наибольших, где $p$ — число положительных. Стоимость $c$ убирается сдвигом $a'_i=a_i-c$. Посчитай число положительных $p'$ в $a'$ и сложи $\max(m,p')$ наибольших, $O(n \log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/155232)

??? question "4. 2224B · Жили, Mex и Max"

    ??? tip "Подсказка 1"
        На какое место выгодно поставить максимальный элемент?

    ??? tip "Подсказка 2"
        Максимум нужно поставить на первую позицию: если он стоял на позиции $i+1$, перенос вперёд увеличивает сумму префиксных максимумов минимум на $i$, а сумма префиксных mex уменьшается не более чем на $t\le i$. Остальные элементы расположи по возрастанию начиная с 0, а повторяющиеся значения отправь в конец.

    [Официальный разбор](https://codeforces.com/blog/entry/153567)

??? question "5. 2249A · Ранговая подпоследовательность"

    ??? tip "Подсказка 1"
        От чего зависит, подходит ли элемент на позицию $j$, кроме самой позиции $j$?

    ??? tip "Подсказка 2"
        Допустимость элемента зависит ещё и от итоговой длины $m$, потому что правый ранг равен $m-j+1$. Что если перебрать $m$?

    ??? tip "Подсказка 3"
        При фиксированном $m$ иди по последовательности слева направо и берись за первый элемент, который подходит на текущую позицию $j$. Почему жадность здесь верна, подскажет обмен: самый ранний подходящий элемент можно подставить вместо любого другого.

    ??? tip "Подсказка 4"
        Перебирай $m$ от $n$ вниз до $1$, первое допустимое $m$ и есть ответ, а если ни одно не подошло, ответ $0$. Асимптотика $O(n^2)$ на тест.

    [Официальный разбор](https://codeforces.com/blog/entry/155516)

??? question "6. 2253C · Сумма различных в матрице"

    ??? tip "Подсказка 1"
        Какая операция над строкой или столбцом реально влияет на итоговую матрицу, если их несколько?

    ??? tip "Подсказка 2"
        Важна только последняя операция для каждой строки и столбца, поэтому различных ненулевых чисел не больше $n+m$.

    ??? tip "Подсказка 3"
        Если применены операции ко всем строкам и всем столбцам, одно число всё равно потеряется, так что различных чисел не больше $n+m-1$. Что делать с числами, которые есть в обоих массивах?

    ??? tip "Подсказка 4"
        Разбей числа на три непересекающихся массива: общие, только из $a$ и только из $b$ (методом двух указателей). Возьми $n$ максимумов из только-$a$, $m$ из только-$b$ и все общие, затем сложи $n+m-1$ наибольших из них. Если чисел не хватает, дополни нулями; время $O((n+m)\log(n+m))$.

    [Официальный разбор](https://codeforces.com/blog/entry/155813)

??? question "7. 1847D · Профессор Хигасиката"

    ??? tip "Подсказка 1"
        Допустим, строка $t$ известна: $t_i$ получается из позиции $f(i)$ строки $s$. Как жадно сделать результат лексикографически наибольшим?

    ??? tip "Подсказка 2"
        Пытайся по порядку сделать $s_{f(1)}=1$, потом $s_{f(2)}=1$ и так далее. Если $f(i)=f(j)$ при $i<j$, индекс $j$ бесполезен, поэтому для каждой позиции $s$ оставляй только первое вхождение в $t$, и длина $t$ не превышает $|s|$.

    ??? tip "Подсказка 3"
        Построить такое $t$ можно разными структурами (set, СНМ, дерево отрезков). При $x$ единицах в $s$ число обменов равно числу позиций $i\le\min(x,|t|)$, где $s_{f(i)}=0$.

    ??? tip "Подсказка 4"
        Запрос меняет ровно одну позицию, то есть $x$ меняется на $x\pm1$, и ответ пересчитывается за $O(1)$: при уменьшении $x$ вычти единицу, если $x\le|t|$ и $s_{f(x)}=0$, при увеличении добавь единицу, если $x<|t|$ и $s_{f(x+1)}=0$. Итого $O(n\log n+q)$.

    [Официальный разбор](https://codeforces.com/blog/entry/117928)

??? question "8. 2252F · Spectral Components"

    ??? tip "Подсказка 1"
        Как решить задачу для одного цвета при $k = 1$: какая вершина оптимальна и через какие рёбра пойдут пути до неё?

    ??? tip "Подсказка 2"
        При $k = 1$ оптимальна одна вершина — центроид вершин цвета. Для ребра $e$ число путей через него равно $w[e] = \min(m_{in}[e], m_{out}[e])$, где это числа вершин цвета по обе стороны ребра.

    ??? tip "Подсказка 3"
        При $k > 1$ связная компонента $S$ из $k$ вершин содержит $k - 1$ ребро. Рёбра внутри $S$ не нужно пересекать, поэтому стоимость равна сумме всех $w[e]$ минус сумма $w[e]$ по рёбрам $S$.

    ??? tip "Подсказка 4"
        Вес $w[e]$ убывает при удалении от центроида, поэтому достаточно жадно взять $k - 1$ рёбер с наибольшими $w[e]$ во всём дереве: они сами образуют связную компоненту с центроидом.

    ??? tip "Подсказка 5"
        Перебирать всё дерево для каждого цвета за $O(N^2)$ слишком долго. Построй для каждого цвета виртуальное дерево по его вершинам за $O(M \log M)$ с помощью LCA.

    ??? tip "Подсказка 6"
        Динамикой снизу вверх по виртуальному дереву найди $m_{in}$. Виртуальное ребро длины $L$ состоит из $L$ реальных рёбер с одинаковым весом $\min(m_{in}, m_c - m_{in})$. Отсортируй пары (вес, количество) по убыванию веса и жадно вычти до $K - 1$ рёбер.

    ??? tip "Подсказка 7"
        Сумма размеров виртуальных деревьев по всем цветам равна $O(n)$, поэтому итоговая асимптотика $O(n \log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/155741)
