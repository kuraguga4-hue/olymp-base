## Подсказки

??? question "1. 1992A · Одни плюсы"

    ??? tip "Подсказка 1"
        К какому из трёх чисел выгодно прибавлять единицу, чтобы произведение выросло сильнее всего?

    ??? tip "Подсказка 2"
        К наименьшему: приращение произведения равно произведению двух остальных. Пять раз найди минимум и прибавь к нему единицу, $O(1)$.

    [Официальный разбор](https://codeforces.com/blog/entry/131461)

??? question "2. 2195C · Последовательность бросков кубика"

    ??? tip "Подсказка 1"
        Когда две грани кубика смежны, и как изменится условие, если разбить последовательность на куски из пары противоположных граней?

    ??? tip "Подсказка 2"
        Разбей $a$ на подсегменты, состоящие из двух противоположных граней. В подсегменте длины $k$ нужно изменить ровно $\lfloor k/2 \rfloor$ позиций, этого всегда хватает и меньше нельзя, так что итог считается за $O(n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/151174)

??? question "3. 1671C · Dolce Vita"

    ??? tip "Подсказка 1"
        Какие пачки выгодно покупать, чтобы купить как можно больше?

    ??? tip "Подсказка 2"
        Самые дешёвые: после сортировки это всегда префикс. Перебирай число пачек $i$ и найди последний день $k_i+1$, когда можно купить $i$ пачек: $k_i=\lfloor (x-(a_1+\dots+a_i))/i\rfloor$ по префиксным суммам. Затем сложи вклад по дням между соседними $k$; итого $O(n\log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/102181)

??? question "4. 2072C · Создание ключей от хранИЛИщ стало моим основным навыком"

    ??? tip "Подсказка 1"
        Как жадно максимизировать MEX, если OR массива не должен содержать лишних битов относительно $x$?

    ??? tip "Подсказка 2"
        Перебирай $m$ от 0 до $\min(n-1, x)$ и храни $v$ — OR уже взятых. Бери $m$, если $v \mid m$ содержит только биты числа $x$, иначе выходи из цикла. Если итоговое OR равно $x$, выводи массив, иначе запиши в $a_n$ число $x$. Время $O(n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/140039)

??? question "5. 1418C · Mortal Kombat Tower"

    ??? tip "Подсказка 1"
        Что можно сказать про то, кто убивает первого босса, и почему это можно вынести отдельно?

    ??? tip "Подсказка 2"
        Если $a_1=1$, первого сложного босса обязательно убивает друг, это стоит одно очко пропуска, и босса можно убрать из рассмотрения.

    ??? tip "Подсказка 3"
        Ходы можно строить так, чтобы каждый отрезок сложных боссов начинался с нашего хода; жадно мы убиваем двух боссов, друг одного.

    ??? tip "Подсказка 4"
        Отрезок из $k$ сложных боссов требует $\lfloor k/3 \rfloor$ очков; сумма по отрезкам, найденным двумя указателями, плюс единица за первого босса, если нужно, даёт ответ.

    [Официальный разбор](https://codeforces.com/blog/entry/82673)

??? question "6. 1336A · Linova и королевство"

    ??? tip "Подсказка 1"
        Если вершина выбрана для туризма, что можно сказать про её родителя в оптимальном ответе?

    ??? tip "Подсказка 2"
        Насколько изменится суммарное счастье, если вместо промышленности для вершины $u$ выбрать туризм? Выразить это можно через глубину вершины и размер её поддерева.

    ??? tip "Подсказка 3"
        Выигрыш от выбора вершины $u$ равен $siz_u-dep_u$: посланник из $u$ не поедет (потеряем $dep_u-1$), а у всех остальных вершин поддерева счастья станет на единицу больше.

    ??? tip "Подсказка 4"
        Посчитай $siz_u-dep_u$ для всех вершин обходом в глубину, отсортируй по убыванию и сложи первые $n-k$ значений. Это $O(n \log n)$, а с nth_element — $O(n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/76099)

??? question "7. 1779D · Борис и его восхитительная прическа"

    ??? tip "Подсказка 1"
        Когда ответа точно нет? И что можно сказать про выбор отрезка стрижки с заданной бритвой?

    ??? tip "Подсказка 2"
        Если $a_i<b_i$ для какого-то $i$, ответа нет. Отрезок стрижки с бритвой размера $x$ выгодно жадно расширять, пока $x\ge a_i$ внутри отрезка.

    ??? tip "Подсказка 3"
        Иди с конца: если $a_n>b_n$, нужно стричь отрезок $[l,n]$ бритвой $b_n$ с минимальным $l$, а если $a_n=b_n$, просто отбрасывай конец. Нужные размеры бритв складывай в массив и в конце проверяй, что он подмножество данных $x_1,\dots,x_m$ (сортировкой или словарём).

    ??? tip "Подсказка 4"
        Сами стрижки отслеживай монотонным стеком, где вершина — самая маленькая бритва. Выкидывай со стека бритвы меньше $b_n$, и если после этого на вершине ровно $b_n$, то позиция уже удовлетворена, иначе добавь $b_n$. Итого $O(n\log n+m\log m)$.

    [Официальный разбор](https://codeforces.com/blog/entry/110629)

??? question "8. 2252F · Spectral Components"

    ??? tip "Подсказка 1"
        Как решить задачу для одного цвета при $k = 1$: какая вершина оптимальна и через какие рёбра пойдут пути до неё?

    ??? tip "Подсказка 2"
        При $k = 1$ оптимальна одна вершина — центроид вершин цвета. Для ребра $e$ число путей через него равно $w[e] = \min(m_{in}[e], m_{out}[e])$, где это числа вершин цвета по обе стороны ребра.

    ??? tip "Подсказка 3"
        При $k > 1$ связная компонента $S$ из $k$ вершин содержит $k - 1$ ребро. Рёбра внутри $S$ не нужно пересекать, поэтому стоимость равна сумме всех $w[e]$ минус сумма $w[e]$ по рёбрам $S$.

    ??? tip "Подсказка 4"
        Вес $w[e]$ убывает при удалении от центроида, поэтому достаточно жадно взять $k - 1$ рёбер с наибольшими $w[e]$ во всём дереве: они сами образуют связную компоненту с центроидом.

    ??? tip "Подсказка 5"
        Перебирать всё дерево для каждого цвета за $O(N^2)$ слишком долго. Построй для каждого цвета виртуальное дерево по его вершинам за $O(M \log M)$ с помощью LCA.

    ??? tip "Подсказка 6"
        Динамикой снизу вверх по виртуальному дереву найди $m_{in}$. Виртуальное ребро длины $L$ состоит из $L$ реальных рёбер с одинаковым весом $\min(m_{in}, m_c - m_{in})$. Отсортируй пары (вес, количество) по убыванию веса и жадно вычти до $K - 1$ рёбер.

    ??? tip "Подсказка 7"
        Сумма размеров виртуальных деревьев по всем цветам равна $O(n)$, поэтому итоговая асимптотика $O(n \log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/155741)
