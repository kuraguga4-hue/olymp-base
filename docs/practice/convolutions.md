## Подсказки

??? question "1. 1792F2 · Покраска графа (сложная версия)"

    ??? tip "Подсказка 1"
        Какую сумму в формуле для $B_n$ можно записать как свёртку двух последовательностей?

    ??? tip "Подсказка 2"
        Если ввести $C_i = \frac{A_i}{i!}$ и $D_i = \frac{B_i}{(i-1)!}$ (при $C_0 = D_0 = 0$), то $B_n = (n-1)! \cdot \sum_{k} C_{n-k} D_k$, то есть почти свёртка.

    ??? tip "Подсказка 3"
        Проблема: чтобы знать $C_i$ и $D_i$, нужно уже знать $B_i$, поэтому одну большую свёртку сразу сделать нельзя. Как считать последовательности постепенно?

    ??? tip "Подсказка 4"
        Строй $A$, $B$, $C$, $D$ параллельно, а свёртку $C$ и $D$ пересчитывай через NTT только раз в $K$ итераций.

    ??? tip "Подсказка 5"
        Если последняя свёртка была после итерации $t$, она уже учитывает все пары $k \le t$, $i - k \le t$. Остальные $2(i-t)$ слагаемых, не больше $O(K)$, добавь вручную.

    ??? tip "Подсказка 6"
        Свёрток будет $\frac{n}{K}$, итого $O(\frac{n^2 \log n}{K} + nK)$.

    ??? tip "Подсказка 7"
        Выбрав $K = \sqrt{n \log n}$, получаешь $O(n \sqrt{n \log n})$.

    [Официальный разбор](https://codeforces.com/blog/entry/111835)

??? question "2. 2194F2 · Опять деревья... (сложная версия)"

    ??? tip "Подсказка 1"
        Что нужно знать о каждом поддереве, чтобы объединять детей, и как комбинируются XOR отрезанных вершин у разных детей?

    ??? tip "Подсказка 2"
        Введи $dp[v][x]$: число способов выбрать рёбра в поддереве $v$, включая ребро в предка, так что XOR отрезанных вершин равен $x$. Для пересчёта нужна XOR-свёртка $c_i = \sum a_j \times b_{j \oplus i}$ значений $dp$ детей.

    ??? tip "Подсказка 3"
        Значения $x$ — это XOR-комбинации множества $b$. Выбери его базис и храни $dp$ в базисе: $x$ станет $2^k$, наивная XOR-свёртка — $4^k$, и этого хватает для F1.

    ??? tip "Подсказка 4"
        Первое ускорение: делай XOR-свёртку через преобразование Адамара (FWHT), будет $O(n \times 2^k \times k)$. Для F2 этого мало, нужно убрать множитель $k$.

    ??? tip "Подсказка 5"
        Храни сразу $hadamard(dp[v])$: тогда свёртка детей — это поточечное произведение за $O(2^k)$. Остаётся шаг с удалением ребра в предка: к $dp[v][0]$ прибавляется сумма $dp[v][b_i \oplus$ xor_subtree$[v]]$.

    ??? tip "Подсказка 6"
        Эта сумма — нулевой элемент свёртки $dp[v]$ с массивом $p$, где единицы стоят на позициях $b_i$. Преобразование свёртки есть поточечное произведение с заранее посчитанным $hadamard(p)$, а нулевой элемент обратного преобразования равен $(\sum q_i) / 2^k$.

    ??? tip "Подсказка 7"
        Вклад xor_subtree$[v]$ учитывается добавлением в свёртку массива с единицей в одной позиции, его преобразование Адамара считается за $O(2^k)$ по определению. Новый $hadamard(dp[v])$ после прибавления к $dp[v][0]$ получается через коэффициенты из определения. В явном виде преобразование считается один раз, для $hadamard(p)$.

    [Официальный разбор](https://codeforces.com/blog/entry/150940)

??? question "3. 2222G · Статистика на дереве"

    ??? tip "Подсказка 1"
        В какой вершине выгодно подвесить дерево, чтобы размеры компонент при удалении вершины были под контролем?

    ??? tip "Подсказка 2"
        Подвесь дерево за центроид и перебирай вершину $o$, которая является LCA пути $(x, y)$. Значение пути выражается через $a_x$, $a_y$ и $n - b_x - b_y$, где $b_u$ — размер компоненты с $u$ после удаления $o$, а $a_u$ — максимальный размер компонент при удалении рёбер пути от $u$ до $o$.

    ??? tip "Подсказка 3"
        Разбери отдельно, какое из трёх значений максимально. Если максимум равен $a_x$, то $b_x \ge \frac{n}{3}$ или $b_y \ge \frac{n}{3}$, а таких компонент после удаления $o$ не более двух.

    ??? tip "Подсказка 4"
        Случай максимума $a_x$ или $a_y$ считай по парам компонент: отсортируй значения $a$ внутри компоненты, ищи нужные $x$ бинпоиском, а вклад остальных накапливай разностными массивами. Каждая вершина обрабатывается $O(1)$ раз, это $O(n \log n)$.

    ??? tip "Подсказка 5"
        Случай максимума $n - b_x - b_y$ похож на свёртку по размерам поддеревьев. Сначала считай, что он максимален всегда, а потом поправь ответ при разборе первого случая, когда $o$ — корень.

    ??? tip "Подсказка 6"
        Сделай свёртку разреженной. Тяжёлое поддерево против лёгких стоит $O(\deg_o)$ на вершину, а различных размеров у лёгких поддеревьев всего $O(\sqrt{sm_o})$, где $sm_o$ — сумма их размеров, поэтому свёртка стоит $O(sm_o)$.

    ??? tip "Подсказка 7"
        По идее DSU on tree сумма $sm_o$ по всем $o$ равна $O(n \log n)$. Вклады при $x=o$ или $y=o$ добавляются отдельно. Итого $O(n \log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/153275)
