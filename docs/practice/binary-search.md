## Подсказки

??? question "1. 1676E · Запросы на  поедание конфет"

    ??? tip "Подсказка 1"
        Какие конфеты выгодно брать, чтобы набрать нужную сумму за наименьшее число штук?

    ??? tip "Подсказка 2"
        Жадно берём самые сладкие: сортируем по убыванию и считаем префиксные суммы (они возрастают). Для каждого запроса $x$ бинарным поиском находим первый префикс с суммой $\ge x$; если его нет, ответ $-1$. Итого $O(q\log n+n\log n)$ с сортировкой.

    [Официальный разбор](https://codeforces.com/blog/entry/102710)

??? question "2. 1742E · Scuza"

    ??? tip "Подсказка 1"
        Что нужно знать про префикс массива, чтобы Скуза смог пройти его до конца при силе $k$?

    ??? tip "Подсказка 2"
        Строим префиксные суммы $b_i$ и префиксные максимумы $m_i$. Для запроса $k$ ищем бинарным поиском наибольший $i$ с $m_i \le k$ (массив $m$ не убывает) и выводим $b_i$. Сложность $O(n\log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/107962)

??? question "3. 1862D · Шарики мороженого"

    ??? tip "Подсказка 1"
        Сколько шариков каждого вида имеет смысл брать и сколько видов мороженого из них получится?

    ??? tip "Подсказка 2"
        Больше двух шариков одного вида брать бессмысленно. Если $x$ видов взято по два шарика, а $y$ видов по одному, мороженых получится $x+\frac{(x+y)(x+y-1)}{2}$ и это должно равняться $n$.

    ??? tip "Подсказка 3"
        При фиксированной сумме $x+y$ значения $x$ и $y$ определяются однозначно, а количество мороженых растёт с суммой. Что можно искать бинарным поиском?

    ??? tip "Подсказка 4"
        Бинарным поиском найди сумму $x+y$, затем восстанови $x$ и $y$. Могут подойти две соседние суммы, тогда выбери вариант с меньшим числом шариков.

    [Официальный разбор](https://codeforces.com/blog/entry/119715)

??? question "4. 1201C · Максимальная медиана"

    ??? tip "Подсказка 1"
        Какие элементы массива выгодно увеличивать, чтобы поднять медиану?

    ??? tip "Подсказка 2"
        Отсортируй массив: медиана зависит только от второй половины, начиная с позиции $(n+1)/2$.

    ??? tip "Подсказка 3"
        Проверь, можно ли получить медиану не меньше $x$: нужно $\sum_{i=(n+1)/2}^{n}\max(0,x-b_i)$ операций, и это должно быть не больше $k$.

    ??? tip "Подсказка 4"
        Эта проверка монотонна по $x$, поэтому бинарным поиском ищем максимальное подходящее $x$. Сложность $O(n\log 10^9)$ после сортировки.

??? question "5. 2226C · Ментально монументально (простая версия)"

    ??? tip "Подсказка 1"
        Какие значения может получить элемент $a_i$ после операции взятия остатка?

    ??? tip "Подсказка 2"
        Остаток либо равен $a_i$ (при $y > a_i$), либо строго меньше $a_i/2$. Значит, значение $x$ можно получить из $a_i = x$ или из $a_i > 2x$.

    ??? tip "Подсказка 3"
        Назовём $k$ хорошим, если можно получить $0..k-1$; это монотонно, ищи максимум бинарным поиском. Проверка: идём от $k-1$ до 0 и берём из мультимножества $x$ или наименьшее значение больше $2x$; итого $O(n \log^2 n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/153150)

??? question "6. 2196C1 · Интерактивный граф (простая версия)"

    ??? tip "Подсказка 1"
        Какие пути гарантированно существуют для каждого ребра и как с их помощью найти ребро?

    ??? tip "Подсказка 2"
        Для каждого ребра есть путь из одного этого ребра, поэтому ищи такие пути бинарным поиском по значению, начиная с $l=0$, $r=2^{30}$, для вершины $1$.

    ??? tip "Подсказка 3"
        После каждой находки игнорируй пути, начинающиеся с уже найденных рёбер, и повторяй, пока не найдёшь все рёбра вершины, затем переходи к вершинам $2, 3, \ldots$. Всего $\log A \cdot (n+m)$ запросов.

    [Официальный разбор](https://codeforces.com/blog/entry/151052)

??? question "7. 2259G · Убрали индекс"

    ??? tip "Подсказка 1"
        Что происходит с элементами после удалённого индекса и до какого места придётся уменьшать значения?

    ??? tip "Подсказка 2"
        Каждый уменьшаемый элемент с новым индексом $j$ (после удаления) становится равным $a_{i-1} + k(j-i+1)$. Элементы с индексами 1 и $n$ удалять бесплатно.

    ??? tip "Подсказка 3"
        Найди последний изменяемый индекс $b$ бинарным поиском: проверяй, что $a_{b+1} \le$ (изменённое $a_b$) $+ k$; условие монотонно.

    ??? tip "Подсказка 4"
        Число операций — сумма $(a_t - (a_{i-1} + (t-i+1)k))$ по $t$ от $i$ до $b$, считается префиксными суммами и формулой арифметической прогрессии.

    [Официальный разбор](https://codeforces.com/blog/entry/156457)

??? question "8. 2228F · Момойо и сеть"

    ??? tip "Подсказка 1"
        Что можно сказать о том, как ответ меняется при увеличении $V$: если значение $V$ достижимо, то достижимо ли меньшее?

    ??? tip "Подсказка 2"
        Ответ монотонен по $V$, значит, его можно искать бинарным поиском, а в каждой проверке нужно уметь отвечать, существует ли путь из $k$ рёбер, у которого все компоненты после удаления пути имеют вес не меньше $V$.

    ??? tip "Подсказка 3"
        Подвесь дерево за вершину $1$ и для каждой вершины $x$ посчитай $dp(x)$ — максимальную длину пути вниз из $x$, на котором для каждой вершины вес её компоненты после разрезания пути не меньше $V$.

    ??? tip "Подсказка 4"
        В вершине $x$ по значениям $dp$ детей ищи двух разных детей $y_1$, $y_2$ с $dp(y_1)+dp(y_2)+2\ge k$ (или одного ребёнка с $dp(y)+1\ge k$, если путь идёт вниз от $x$).

    ??? tip "Подсказка 5"
        Отсортируй значения $dp$ детей и найди такую пару двумя указателями за $O(\deg(x)\log \deg(x))$ на вершину.

    ??? tip "Подсказка 6"
        Итог: бинарный поиск по $V$, внутри проверки DFS с $dp$ и двумя указателями, общая сложность $O(n\log V\log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/153619)
