## Подсказки

??? question "1. 1676E · Запросы на  поедание конфет"

    ??? tip "Подсказка 1"
        Какие конфеты выгодно брать, чтобы набрать нужную сумму за наименьшее число штук?

    ??? tip "Подсказка 2"
        Жадно берём самые сладкие: сортируем по убыванию и считаем префиксные суммы (они возрастают). Для каждого запроса $x$ бинарным поиском находим первый префикс с суммой $\ge x$; если его нет, ответ $-1$. Итого $O(q\log n+n\log n)$ с сортировкой.

    [Официальный разбор](https://codeforces.com/blog/entry/102710)

??? question "2. 1613C · Отравленный кинжал"

    ??? tip "Подсказка 1"
        Как посчитать суммарный урон, если значение $k$ зафиксировано?

    ??? tip "Подсказка 2"
        Урон равен $k+\sum_{i=1}^{n-1}\min(k,a_{i+1}-a_i)$ и растёт с $k$. Бинарным поиском ищем минимальное $k$, при котором урон не меньше $h$.

    [Официальный разбор](https://codeforces.com/blog/entry/97467)

??? question "3. 1742E · Scuza"

    ??? tip "Подсказка 1"
        Что нужно знать про префикс массива, чтобы Скуза смог пройти его до конца при силе $k$?

    ??? tip "Подсказка 2"
        Строим префиксные суммы $b_i$ и префиксные максимумы $m_i$. Для запроса $k$ ищем бинарным поиском наибольший $i$ с $m_i \le k$ (массив $m$ не убывает) и выводим $b_i$. Сложность $O(n\log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/107962)

??? question "4. 1703F ·  Очередная задача про пары, удовлетворяющие неравенству"

    ??? tip "Подсказка 1"
        Какие элементы вообще могут входить в хорошую пару?

    ??? tip "Подсказка 2"
        Условие разбивается на $a_i<i$, $i<a_j$, $a_j<j$. Элементы с $a_i \ge i$ можно выбросить.

    ??? tip "Подсказка 3"
        Среди оставшихся нужно считать пары $i<a_j$. Идём по $j$ слева направо и храним список индексов $i$ уже просмотренных элементов; он остаётся отсортированным.

    ??? tip "Подсказка 4"
        Для каждого $j$ бинарным поиском считаем, сколько индексов в списке меньше $a_j$, и добавляем $j$ в конец списка. Сложность $O(n\log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/104786)

??? question "5. 1862D · Шарики мороженого"

    ??? tip "Подсказка 1"
        Сколько шариков каждого вида имеет смысл брать и сколько видов мороженого из них получится?

    ??? tip "Подсказка 2"
        Больше двух шариков одного вида брать бессмысленно. Если $x$ видов взято по два шарика, а $y$ видов по одному, мороженых получится $x+\frac{(x+y)(x+y-1)}{2}$ и это должно равняться $n$.

    ??? tip "Подсказка 3"
        При фиксированной сумме $x+y$ значения $x$ и $y$ определяются однозначно, а количество мороженых растёт с суммой. Что можно искать бинарным поиском?

    ??? tip "Подсказка 4"
        Бинарным поиском найди сумму $x+y$, затем восстанови $x$ и $y$. Могут подойти две соседние суммы, тогда выбери вариант с меньшим числом шариков.

    [Официальный разбор](https://codeforces.com/blog/entry/119715)

??? question "6. 1324D · Пара тем"

    ??? tip "Подсказка 1"
        Как упростить условие $a_i+a_j>b_i+b_j$, чтобы оно зависело от одного числа на элемент?

    ??? tip "Подсказка 2"
        Переходим к $c_i=a_i-b_i$: нужно посчитать пары $i<j$ с $c_i+c_j>0$. Отсортируем $c$.

    ??? tip "Подсказка 3"
        Идём по отсортированному $c$ слева направо, пропуская $c_i \le 0$; для $c_i>0$ подходят все $j<i$ с $c_j \ge -c_i+1$.

    ??? tip "Подсказка 4"
        Самую левую такую позицию $j$ находим lower_bound-ом и прибавляем к ответу $i-j$. Сложность $O(n\log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/74714)

??? question "7. 1968G1 · Деление + LCP (простая версия)"

    ??? tip "Подсказка 1"
        Если можно разбить строку хотя бы на $k$ частей с общим префиксом длины $\ell$, то можно ли это сделать и для $\ell-1$?

    ??? tip "Подсказка 2"
        Да, значит, ответ можно искать бинарным поиском по $\ell$. Осталось проверять фиксированное $\ell$.

    ??? tip "Подсказка 3"
        Первая часть всегда префикс строки. Чему равна длина наибольшего общего префикса строки и подстроки, начинающейся в позиции $p$ (подумай про Z-функцию)?

    ??? tip "Подсказка 4"
        Посчитай Z-функцию и жадно набирай отрезки: берёшь отрезок с началом $p$, если $z_p \ge \ell$, и идёшь дальше за его конец. Если набралось хотя бы $k$ отрезков, то $\ell$ подходит. Всего $O(n\log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/129096)

??? question "8. 2228F · Момойо и сеть"

    ??? tip "Подсказка 1"
        Что можно сказать о том, как ответ меняется при увеличении $V$: если значение $V$ достижимо, то достижимо ли меньшее?

    ??? tip "Подсказка 2"
        Ответ монотонен по $V$, значит, его можно искать бинарным поиском, а в каждой проверке нужно уметь отвечать, существует ли путь из $k$ рёбер, у которого все компоненты после удаления пути имеют вес не меньше $V$.

    ??? tip "Подсказка 3"
        Подвесь дерево за вершину $1$ и для каждой вершины $x$ посчитай $dp(x)$ — максимальную длину пути вниз из $x$, на котором для каждой вершины вес её компоненты после разрезания пути не меньше $V$.

    ??? tip "Подсказка 4"
        В вершине $x$ по значениям $dp$ детей ищи двух разных детей $y_1$, $y_2$ с $dp(y_1)+dp(y_2)+2\ge k$ (или одного ребёнка с $dp(y)+1\ge k$, если путь идёт вниз от $x$).

    ??? tip "Подсказка 5"
        Отсортируй значения $dp$ детей и найди такую пару двумя указателями за $O(\deg(x)\log \deg(x))$ на вершину.

    ??? tip "Подсказка 6"
        Итог: бинарный поиск по $V$, внутри проверки DFS с $dp$ и двумя указателями, общая сложность $O(n\log V\log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/153619)
