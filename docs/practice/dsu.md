## Подсказки

??? question "1. 1167C · Распространение новостей"

    ??? tip "Подсказка 1"
        Как переформулировать задачу на языке графов и что тогда будет ответом для человека?

    ??? tip "Подсказка 2"
        Люди — вершины, общая группа даёт ребро; новость получают все в компоненте связности, ответ — её размер.

    ??? tip "Подсказка 3"
        Рёбер может быть $O(n^2)$, но достаточно соединять соседей внутри каждой группы: компоненты не изменятся.

    ??? tip "Подсказка 4"
        Объедини людей в СНМ (или обходом в глубину) по этим рёбрам и выведи размер компоненты для каждого; асимптотика $O(n+\sum k_i)$.

    [Официальный разбор](https://codeforces.com/blog/entry/67058)

??? question "2. 1263D · Секретные пароли"

    ??? tip "Подсказка 1"
        Что объединяет пароли, у которых есть общая буква, и как это выразить через граф?

    ??? tip "Подсказка 2"
        Построй двудольный граф: 26 вершин-букв и $n$ вершин-паролей, ребро — буква входит в пароль.

    ??? tip "Подсказка 3"
        Эквивалентность паролей по определению означает принадлежность одной компоненте связности этого графа.

    ??? tip "Подсказка 4"
        Ответ — число компонент связности (учитывая только компоненты с паролями), асимптотика $O(n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/71844)

??? question "3. 1213G · Запросы на пути"

    ??? tip "Подсказка 1"
        В каком порядке выгодно отвечать на запросы, чтобы не пересчитывать всё заново?

    ??? tip "Подсказка 2"
        Отсортируй рёбра и запросы по весу и храни текущий ответ $res$ для набора рёбер.

    ??? tip "Подсказка 3"
        Для запроса веса $cw$ объедини в DSU компоненты по всем рёбрам с $w_i \le cw$, храня размеры компонент.

    ??? tip "Подсказка 4"
        При объединении компонент размеров $s_1$ и $s_2$: $res := res - \binom{s_1}{2} - \binom{s_2}{2} + \binom{s_1+s_2}{2}$; ответ на запрос — $res$, асимптотика $O(n\log n + m\log m)$.

    [Официальный разбор](https://codeforces.com/blog/entry/69464)

??? question "4. 2020D · Соедини точки"

    ??? tip "Подсказка 1"
        Чем ограничено значение $d_i$ и как это можно использовать?

    ??? tip "Подсказка 2"
        Раз $d_i$ мал (не более $10$), можно хранить $dp[j][w]$ — число отрезков с шагом $w$, покрывающих вершину $j$ (где $j$ не является концом $a+kd$), и $id[j][w]$ — вершину, представляющую компоненту, в которую сейчас входит $j$.

    ??? tip "Подсказка 3"
        Ещё храни $Start\_cnt[j][w]$ и $End\_cnt[j][w]$ — сколько троек начинаются и заканчиваются в $j$ с шагом $w$. Начни с $dp[j][w]=Start\_cnt[j][w]-End\_cnt[j][w]$.

    ??? tip "Подсказка 4"
        Переход: $dp[j][w]$ получается из $dp[j-w][w]$, и если оно ненулевое, объедини $j$ с $id[j-w][w]$ в СНМ, прибавь $dp[j-w][w]$ и возьми $id[j][w]=id[j-w][w]$. Итого $O(\max_d \cdot n \log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/134516)

??? question "5. 1242B · 0-1 MST"

    ??? tip "Подсказка 1"
        Чему равен вес минимального остова, если смотреть только на нулевые рёбра?

    ??? tip "Подсказка 2"
        Если в подграфе из рёбер веса 0 всего $k$ компонент, ответ равен $k-1$, так что нужно посчитать эти компоненты.

    ??? tip "Подсказка 3"
        Рёбер веса 0 слишком много, поэтому добавляй вершины по одной: для вершины $v$ и каждой нулевой компоненты считай рёбра веса 1 из неё в $v$.

    ??? tip "Подсказка 4"
        Если таких рёбер меньше размера компоненты, значит есть нулевое ребро, и компоненту надо объединить с $v$ в DSU; общее время $O(m+n\log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/71216)

??? question "6. 1927F · Микроцикл"

    ??? tip "Подсказка 1"
        Какое ребро будет самым лёгким в искомом цикле, если добавлять рёбра в порядке убывания веса?

    ??? tip "Подсказка 2"
        Добавляй рёбра в СНМ по убыванию веса. Рёбра, объединившие разные множества, образуют лес, а запомнить нужно последнее ребро, которое не удалось добавить: оно и есть самое лёгкое ребро цикла.

    ??? tip "Подсказка 3"
        Сам цикл — это ребро плюс путь между его концами в построенном графе, где циклов нет, так что путь ищется как путь в дереве.

    [Официальный разбор](https://codeforces.com/blog/entry/125597)

??? question "7. 1851G · Влад и горы"

    ??? tip "Подсказка 1"
        Как изменяется энергия на пути $i\to j\to k$, и от чего итоговая энергия зависит?

    ??? tip "Подсказка 2"
        Энергия на пути зависит только от разницы высот первой и последней гор: $h_i-h_k$. Значит, из $a$ можно попасть в любую вершину, до которой есть путь, не проходящий через вершины с высотой больше $h_a+e$.

    ??? tip "Подсказка 3"
        Таким образом, для запроса нужно проверить, лежат ли $a$ и $b$ в одной компоненте, где все вершины имеют высоту не больше $h_a+e$.

    ??? tip "Подсказка 4"
        Отсортируй запросы по $h_a+e$, а рёбра графа по $\max(h_u,h_v)$. Перед каждым запросом добавь в СНМ все ещё не добавленные рёбра с $\max(h_u,h_v)\le h_a+e$.

    ??? tip "Подсказка 5"
        После этого ответ на запрос — лежат ли $a$ и $b$ в одной компоненте связности.

    [Официальный разбор](https://codeforces.com/blog/entry/118667)

??? question "8. 1857G · Подсчет графов"

    ??? tip "Подсказка 1"
        Почему в нужных графах всегда $n$ вершин и какие веса может иметь новое ребро между $u$ и $v$, чтобы остов остался прежним?

    ??? tip "Подсказка 2"
        Пусть $P(u,v)$ — максимальный вес на простом пути между $u$ и $v$ в дереве. Новое ребро можно добавить с любым весом из $[P(u,v)+1,S]$, и такие рёбра независимы друг от друга.

    ??? tip "Подсказка 3"
        Для каждой пары вершин есть $S-P(u,v)$ вариантов веса или ребро не добавлять, поэтому ответ — произведение $\prod (S-P(u,v)+1)$ по парам $u<v$.

    ??? tip "Подсказка 4"
        Отсортируй рёбра дерева по весу и добавляй их по одному, поддерживая СНМ. Вес $w_i$ не меньше предыдущих, а $u_i$ и $v_i$ из разных компонент размеров $s_u$ и $s_v$.

    ??? tip "Подсказка 5"
        Максимум на путях, проходящих через добавленное ребро, равен $w_i$, таких путей (кроме самого ребра) $s_u\cdot s_v-1$, поэтому умножай ответ на $(S-w_i+1)^{s_u\cdot s_v-1}$ быстрым возведением в степень. Итого $O(n\log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/119134)
