## Подсказки

??? question "1. 1633D · Сделай равными"

    ??? tip "Подсказка 1"
        Для каждого $b_i$ сначала подумай: сколько минимум операций нужно, чтобы получить его из $1$, и как это посчитать для всех чисел сразу?

    ??? tip "Подсказка 2"
        После этого, как можно переформулировать выбор, какие элементы довести до $b_i$, если у каждого есть своя цена по операциям и своя выгода?

    ??? tip "Подсказка 3"
        Это задача о рюкзаке: предмет $i$ весит $d_{b_i}$ и стоит $c_i$, суммарный вес не больше $k$. Обычное решение за $O(nk)$ медленно. Что можно сказать про максимальное значение $d_i$ при $i \le 10^3$ и как это поможет ограничить $k$?

    ??? tip "Подсказка 4"
        Посчитай $d_i$ через BFS или ДП по переходам $i \to i + \lfloor i/x \rfloor$. Затем реши рюкзак с весами $d_{b_i}$ и стоимостями $c_i$. Так как $d_i \le 12$, полезно взять $k=\min(k,12n)$, и рюкзак работает за $O(n \cdot 12n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/99539)

??? question "2. 2138C2 · Мейпл и красота дерева (сложная версия)"

    ??? tip "Подсказка 1"
        Чему равен максимально возможный ответ и чем он ограничен, если смотреть на глубины листьев?

    ??? tip "Подсказка 2"
        Ответ не превосходит $d$ — минимальной глубины листа. Чтобы достичь $d$, у всех вершин одной глубины (среди первых $d$ уровней) должна быть одинаковая метка.

    ??? tip "Подсказка 3"
        Посчитай $c_i$ — число вершин глубины $i$ для $i = 1, \ldots, d$. Нужно выбрать несколько чисел из $c$ с суммой $k$ — это задача о рюкзаке, решаемая за $O(n^2)$.

    ??? tip "Подсказка 4"
        Если $d$ недостижим, то всегда достижимо $d-1$. Для листьев разной глубины оптимально учитывать только первые $d$ вершин на каждом пути, остальным метки ставятся произвольно.

    ??? tip "Подсказка 5"
        Итог: ответ $d$, если рюкзак даёт нужную сумму, иначе $d-1$; время $O(n^2)$, его можно ускорить битсетом.

    [Официальный разбор](https://codeforces.com/blog/entry/146172)
