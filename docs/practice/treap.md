??? question "3. 2242F · Летние каникулы"

    ??? tip "Подсказка 1"
        Как зависит итоговое количество долларов от значения перед началом суффикса, и можно ли хранить эту зависимость целиком?

    ??? tip "Подсказка 2"
        Количество долларов никогда не превосходит $2n$: если значение хотя бы $a_i$, оно уменьшается, иначе после прибавления оно меньше $2a_i \le 2n$. Поэтому достаточно хранить значения для всех начальных сумм $j$ от $0$ до $2n-1$.

    ??? tip "Подсказка 3"
        Иди справа налево и поддерживай $dp[j]$ — итог обработки текущего суффикса при начальном значении $j$. Сначала $dp[j] = j$. Ответ для суффикса — $dp[0]$.

    ??? tip "Подсказка 4"
        При добавлении слева элемента $x$: $new\_dp[j] = dp[j+x]$ при $j < x$ и $dp[j-x]$ при $j \ge x$.

    ??? tip "Подсказка 5"
        То есть новый массив — это $dp[x \ldots 2x-1]$, склеенный с $dp[0 \ldots 2n-x]$. Нужна структура, умеющая вырезать подотрезки и склеивать их.

    ??? tip "Подсказка 6"
        Храни $dp$ в персистентном декартовом дереве по неявному ключу и делай split и merge за $O(\log n)$ на каждый элемент. При склейке копий приоритетов нет: делай корнем левое дерево с вероятностью $\frac{sz_l}{sz_l+sz_r}$. Итого $O(n\log n)$ по времени и памяти.

    [Официальный разбор](https://codeforces.com/blog/entry/155047)
