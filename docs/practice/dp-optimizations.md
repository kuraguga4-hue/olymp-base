## Подсказки

??? question "1. 833B · Кондитерская"

    ??? tip "Подсказка 1"
        Какое состояние динамики напрашивается, если нужно разложить первые $n$ пирожных по $k$ коробкам?

    ??? tip "Подсказка 2"
        Пусть $dp(k,n)$ — ответ для первых $n$ пирожных и $k$ коробок; пересчёт $dp(k,n)=\max_i dp(k-1,i-1)+c(i,n)$, где $c(i,n)$ — число различных типов на отрезке.

    ??? tip "Подсказка 3"
        Первый способ: для каждого слоя держи дерево отрезков на максимум с ленивыми обновлениями, где в ячейке $j$ лежит $dp(k-1,j)+c(j+1,i)$.

    ??? tip "Подсказка 4"
        При переходе $i \to i+1$ ко всем $j$ от предыдущей позиции такого же типа (невключительно) до $i$ прибавляется единица; нужен массив $prev[i]$.

    ??? tip "Подсказка 5"
        Тогда $dp(k,i)$ — максимум на префиксе дерева, слои считаются по очереди. Другой способ из разбора: самая левая оптимальная граница не убывает с ростом $n$, поэтому слой можно считать оптимизацией «разделяй и властвуй», а $c(i,n)$ — персистентным деревом отрезков.

    [Официальный разбор](https://codeforces.com/blog/entry/53567)

??? question "2. 1083E · Орехус и прямоугольники"

    ??? tip "Подсказка 1"
        Что можно сказать про порядок $y_i$, если отсортировать прямоугольники по $x_i$ и учесть, что вложенных прямоугольников нет?

    ??? tip "Подсказка 2"
        Как задать состояние ДП так, чтобы знать, какой прямоугольник выбран последним?

    ??? tip "Подсказка 3"
        Пусть $dp_i$ — максимум, достижимый на подмножестве из первых $i$ прямоугольников, содержащем $i$-й. Как выразить, сколько площади $i$-й добавляет к уже выбранному последнему $j$, если пересечение у них общее?

    ??? tip "Подсказка 4"
        Переход имеет вид $dp_i = \max_{j<i}(dp_j + x_i y_i - x_j y_i)$. Какой вид имеет выражение, зависящее от $j$, при фиксированном $y_i$, и какой приём помогает искать максимум таких значений?

    ??? tip "Подсказка 5"
        Отсортируй по $x$ (тогда $y$ убывает), посчитай $dp_i = \max_{j<i}(dp_j + x_i y_i - x_j y_i)$, где $x_j y_i$ — общая площадь с предыдущим выбранным. Максимум по $j$ ищется оптимизацией выпуклой оболочкой прямых (convex hull trick), итого $O(n \log n)$, а на уже отсортированных данных $O(n)$.

??? question "3. 932F · Сбежать через лист"

    ??? tip "Подсказка 1"
        Какое динамическое состояние напрашивается, если нужно найти минимальную стоимость пути до листа из вершины $i$?

    ??? tip "Подсказка 2"
        Пусть $dp[i]$ равно минимальной стоимости добраться до листа из вершины $i$. Тогда $dp[i] = \min_j (a[i] \cdot b[j] + dp[j])$ по вершинам $j \neq i$ из поддерева $i$. Как выглядит это выражение как функция от $a[i]$?

    ??? tip "Подсказка 3"
        Это минимум значения в точке $x=a[i]$ по прямым $y=b[j]x+dp[j]$, то есть задача для convex hull trick: после подсчёта $dp[i]$ в структуру добавляется прямая с наклоном $b[i]$ и свободным членом $dp[i]$.

    ??? tip "Подсказка 4"
        Нужно хранить нижнюю огибающую только для вершин текущего поддерева, поэтому для каждого сына строится своя огибающая.

    ??? tip "Подсказка 5"
        Огибающие лёгких сыновей сливаются в огибающую тяжёлого (малое в большое), затем запросом в точке $a[i]$ получаем $dp[i]$ и добавляем новую прямую.

    ??? tip "Подсказка 6"
        Слияние малого в большое даёт $O(n \log n)$ добавлений, каждое добавление и запрос стоят $O(\log n)$, итого $O(n \log^2 n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/57796)

??? question "4. 2107F2 · Велосипедный спорт (сложная версия)"

    ??? tip "Подсказка 1"
        Какому условию должна удовлетворять позиция $p$, с которой имеет смысл переносить элемент, если смотреть на элементы правее неё?

    ??? tip "Подсказка 2"
        Для $p$ должно выполняться $a_i>a_p$ при всех $i>p$, то есть такие $p$ образуют монотонный стек. Для второй позиции $p2$ выгодно брать либо $p2=p$, либо $p2=n$.

    ??? tip "Подсказка 3"
        Значит, динамика идёт по стеку: лучший ответ — выбрать $p_i$, перенести его в конец и повторять процесс.

    ??? tip "Подсказка 4"
        Вклад элемента стека — число элементов между ним и предыдущим элементом стека, строго больших его значения, плюс он сам, умноженный на расстояние до предыдущего (число обменов соседей и стоимость прохода).

    ??? tip "Подсказка 5"
        При добавлении числа выталкивай хвост стека, пока он не станет строго меньше текущего, пересчитывай вклад и обновляй ответ минимумом.

    ??? tip "Подсказка 6"
        Минимум вычисляется деревом Ли Чао или бинарным поиском по выпуклой оболочке, общая сложность $O(n\log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/142642)

??? question "5. 2125F · Тимофей и докер"

    ??? tip "Подсказка 1"
        Могут ли вхождения слова «docker» в строке пересекаться, и что это даёт?

    ??? tip "Подсказка 2"
        Буквы «docker» различны, поэтому вхождения не пересекаются. Посчитай максимум $mx$ достижимого значения и число вхождений $cnt$ в $s$.

    ??? tip "Подсказка 3"
        Если нужно меньше вхождений, чем уже есть, ответ обновляется как $cnt-i$ по подходящим $i$. Сложный случай — когда вхождений нужно больше: там нужна динамика $dp[x][y]$ — минимум замен на префиксе длины $x$, чтобы вхождений было ровно $y$.

    ??? tip "Подсказка 4"
        Эта динамика за $O(|s|\cdot i)$ нужна только один раз, для первого $i\ge cnt$, при котором достигается $mx$.

    ??? tip "Подсказка 5"
        Функция $g(x)=dp[|s|][x]$ не убывает и нестрого выпукла: стоимость $w(k,i)$ удовлетворяет неравенству четырёхугольника.

    ??? tip "Подсказка 6"
        Из выпуклости следует, что $dp[|s|][i]$ можно найти лямбда-оптимизацией (aliens trick); итоговая сложность $O(n+|s|\cdot\log C)$.

    [Официальный разбор](https://codeforces.com/blog/entry/144998)
