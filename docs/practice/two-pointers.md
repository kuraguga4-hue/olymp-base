## Подсказки

??? question "1. 1669F · Съедая конфеты"

    ??? tip "Подсказка 1"
        Что происходит с суммой Боба, пока она меньше суммы Алисы, и в какую сторону можно двигать его указатель при росте суммы Алисы?

    ??? tip "Подсказка 2"
        Двигай левый указатель $i$ вправо, прибавляя $a_i$ к сумме Алисы, а правый указатель $j$ влево, пока сумма Боба не станет не меньше суммы Алисы. Если указатели пересеклись, заканчивай; если суммы равны, обнови ответ. Каждый указатель проходит массив один раз, итого $O(n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/102101)

??? question "2. 2193D · Игра с монстрами"

    ??? tip "Подсказка 1"
        Как изменится число доступных мечей при уменьшении сложности уровня, если мечи отсортированы по силе?

    ??? tip "Подсказка 2"
        Отсортируй мечи по убыванию силы. Для сложности $a_i$ можно использовать $i$ мечей. Поддерживай указатель на число проходимых уровней и бери максимальный счёт по всем сложностям, это $O(n)$ после сортировки.

    [Официальный разбор](https://codeforces.com/blog/entry/150510)

??? question "3. 1133C · Сбалансированная команда"

    ??? tip "Подсказка 1"
        Как упорядочить студентов, чтобы подходящая команда выглядела как подотрезок?

    ??? tip "Подсказка 2"
        Отсортируй умения по неубыванию. Для каждого студента $i$ двумя указателями находи максимальное число студентов $j$, для которых $a_j - a_i \le 5$. Ответ — максимальная длина такого окна.

    [Официальный разбор](https://codeforces.com/blog/entry/65807)

??? question "4. 1582C · Баба Капа вяжет шарф"

    ??? tip "Подсказка 1"
        Если удалять можно только одну букву, как это ограничивает варианты, и что делать с каждой такой буквой?

    ??? tip "Подсказка 2"
        Перебирай удаляемую букву $c$ от a до z и для каждой считай минимальное число удалений независимо. Ставь указатели $l$ и $r$ на концы строки: если символы равны, сдвигай оба; если нет, удаляй тот, который равен $c$ (прибавляй к счётчику), а если ни один не равен $c$, то для этой буквы палиндрома не получить. Ответ — минимум по буквам, асимптотика $O(26 \cdot n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/96267)

??? question "5. 2051D · Подсчет количества пар"

    ??? tip "Подсказка 1"
        Как свести подсчёт пар с суммой остальных элементов в отрезке $[x, y]$ к подсчёту пар с суммой меньше границы?

    ??? tip "Подсказка 2"
        Посчитай количество пар с суммой остальных меньше $y+1$ и вычти количество пар с суммой меньше $x$. Сумму остальных считай как $s - a_i - a_j$, где $s$ — сумма всех. Отсортируй массив: для каждого $i$ подходящие $j$ образуют суффикс, границу находи двумя указателями или бинарным поиском. Пары с $i=j$ вычти отдельно, посчитав такие $i$, что $s - 2a_i < x$, а пары, посчитанные дважды (с $i>j$), раздели на $2$. Итого $O(n \log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/137623)

??? question "6. 2149E · Скрытые знания древних"

    ??? tip "Подсказка 1"
        Если зафиксировать левую границу $i$, какие правые границы подходят по условию на число различных чисел и на длину?

    ??? tip "Подсказка 2"
        Поддерживай два скользящих окна: $x$ — граница, где на $[i..x]$ ровно $k$ различных, и $y$ — максимальный индекс, что на $[i..y-1]$ не более $k$ различных. Допустимые по числу различных правые концы лежат в $[x,\ y-1]$.

    ??? tip "Подсказка 3"
        Пересеки этот отрезок с ограничением на длину: правые концы должны лежать в $[i+l-1,\ i+r-1]$.

    ??? tip "Подсказка 4"
        Количество подходящих подотрезков с началом $i$ равно $\max(0,\ \min(y-1,\ i+r-1) - \max(x,\ i+l-1) + 1)$. Двигаем $i$, обновляем счётчики; с сжатием координат время $O(n \log n)$.

??? question "7. 580B · Кефа и компания"

    ??? tip "Подсказка 1"
        Как изменится задача, если упорядочить друзей по количеству денег?

    ??? tip "Подсказка 2"
        После сортировки по деньгам подходящая компания — это подотрезок отсортированного массива.

    ??? tip "Подсказка 3"
        Для каждой левой границы нужно найти самую правую границу, при которой разница денег меньше $d$, и эти границы двигаются только вправо.

    ??? tip "Подсказка 4"
        Отсортируй друзей по деньгам и двигай два указателя, поддерживая сумму дружбы в окне, пока разница денег крайних меньше $d$. Ответ — максимум суммы по окнам. Асимптотика $O(n \log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/20468)

??? question "8. 2226E · Ментально монументально (сложная версия)"

    ??? tip "Подсказка 1"
        Как ответ для префикса зависит от ответа для префикса на один короче?

    ??? tip "Подсказка 2"
        Ответ для префикса не меньше ответа для префикса на один элемент короче. Поэтому используй два указателя: по префиксу и по ответу, увеличивая ответ, пока можно.

    ??? tip "Подсказка 3"
        Чтобы проверять возможность ответа $k$, жадно «закрепи» как можно больше чисел меньше $k$, а остальные числа (offerers) должны покрыть нужные остатки (receivers). Каждый receiver сопоставляется с offerer, больше чем вдвое превосходящим его.

    ??? tip "Подсказка 4"
        Проверка паросочетания: для префикса из $p$ самых больших receivers с наименьшим $q$ нужно хотя бы $p$ offerers не меньше $2q+1$, и так для всех префиксов.

    ??? tip "Подсказка 5"
        Заведи дерево отрезков, где в позиции $i$ стоит (число offerers $\ge 2i+1$) минус (число receivers $\ge i$). Ответ возможен, когда минимум неотрицателен. Переход к следующему префиксу и увеличение ответа — добавления на отрезке. Итого $O(n\log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/153150)
