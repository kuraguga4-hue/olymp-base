## Подсказки

??? question "1. 1343B · Сбалансированный массив"

    ??? tip "Подсказка 1"
        При каком условии на $n$ чётности половин вообще могут сойтись?

    ??? tip "Подсказка 2"
        Если $n$ не делится на 4, ответ NO, иначе YES: возьми $[2,4,\dots,n,1,3,\dots,n-1]$ и прибавь $n/2$ к последнему элементу.

    [Официальный разбор](https://codeforces.com/blog/entry/76352)

??? question "2. 1862B · Игра в последовательность"

    ??? tip "Подсказка 1"
        Между какими соседними числами нужно что-то вставить, чтобы Вика могла получить исходную последовательность?

    ??? tip "Подсказка 2"
        Для каждой пары соседних чисел, где левое меньше правого, вставь между ними единицу: правое число хотя бы 2, поэтому Вика удалит только добавленные единицы.

    [Официальный разбор](https://codeforces.com/blog/entry/119715)

??? question "3. 2247A · Нулевая сумма"

    ??? tip "Подсказка 1"
        Что можно сказать о сумме элементов после одной операции?

    ??? tip "Подсказка 2"
        Если сумма по модулю 4 не равна 0, ответ NO. Иначе операциями с индексами $1,2,\ldots,n-1$ сделай первые элементы равными $1,-1,1,\ldots$ чередуя знаки; тогда модуль суммы не больше 2, а значит она равна 0, потому что 0 единственное число в этом диапазоне, кратное 4.

    [Официальный разбор](https://codeforces.com/blog/entry/155337)

??? question "4. 2247B · Еще один конструктив"

    ??? tip "Подсказка 1"
        Почему при $m<k$ ответа может не быть, если смотреть на остатки префиксных сумм по модулю $m$?

    ??? tip "Подсказка 2"
        При $m<k$ ответ $-1$ (принцип Дирихле для остатков префиксных сумм). Иначе поставь $a_j=1$ для $j \bmod k \neq 0$ и $a_j=x-k+1$ для $j \bmod k=0$.

    [Официальный разбор](https://codeforces.com/blog/entry/155337)

??? question "5. 2259D · MEX мультимножеств"

    ??? tip "Подсказка 1"
        Как устроен ответ в зависимости от количества нулей в $a$?

    ??? tip "Подсказка 2"
        Нулей нет — любое разбиение подходит. Один нуль — невозможно. Два и больше: первый нуль в $A$, остальные нули в $B$, все ненулевые в $C$; тогда MEX равны 1, 1, 0 и условие выполняется.

    [Официальный разбор](https://codeforces.com/blog/entry/156457)

??? question "6. 2219A · Таблица L"

    ??? tip "Подсказка 1"
        Что можно сказать о суммарном числе рёбер сетки $m\times n$ и как оно связано с $p$ и $q$?

    ??? tip "Подсказка 2"
        Условие: $p+2q=m(n+1)+n(m+1)$ и $p\ge|m-n|$; достаточность показывается явной конструкцией.

    ??? tip "Подсказка 3"
        Пусть $m\ge n$. Тогда $n\le\sqrt{p/2+q}$; перебирай $n$ до этого значения, считай $m=(p+2q-n)/(2n+1)$ и проверяй целость и $|m-n|\le p$. Иначе $-1$. Сложность $O(\sqrt{p+2q})$.

    [Официальный разбор](https://codeforces.com/blog/entry/152936)

??? question "7. 1922E · Возрастающие подпоследовательности"

    ??? tip "Подсказка 1"
        Как меняется число возрастающих подпоследовательностей, если дописать в конец массива один новый элемент?

    ??? tip "Подсказка 2"
        Удобнее всего дописывать новый минимум или новый максимум. Новый минимум добавляет только одну подпоследовательность (из него самого): $x \to x+1$; новый максимум продолжает любую из них: $x \to 2x$.

    ??? tip "Подсказка 3"
        Построй рекурсивную функцию $f(x)$: для нечётного $x$ это $f(x-1)$ плюс минимум, для чётного — $f(x/2)$ плюс максимум.

    ??? tip "Подсказка 4"
        Две операции подряд типа $x \to x-1$ невозможны, поэтому каждые две операции $x$ уменьшается хотя бы вдвое, а длина массива укладывается в 200.

    [Официальный разбор](https://codeforces.com/blog/entry/124890)

??? question "8. 1583F · Защитник детских мечт"

    ??? tip "Подсказка 1"
        Сколько вершин можно покрасить $c$ цветами, если нет одноцветного пути длины $k$?

    ??? tip "Подсказка 2"
        Минимальное число цветов равно $\lceil \log_k n \rceil$. Для построения раздели вершины на $k$ последовательных отрезков примерно равной длины.

    ??? tip "Подсказка 3"
        Рёбра между разными отрезками покрась в один цвет, а внутри каждого отрезка рекурсивно используй остальные цвета.

    ??? tip "Подсказка 4"
        Одноцветный путь идёт между подотрезками одного размера внутри одного большего, а их всего $k$, поэтому путь не длиннее $k - 1$. Глубина рекурсии равна $\lceil \log_k n \rceil$.

    ??? tip "Подсказка 5"
        Нижнюю оценку докажи индукцией: $n \le k^c$ при $c$ цветах. Выбери цвет и раздели вершины на $k$ групп $s_j$ по длине самого длинного пути этого цвета, оканчивающегося в вершине; внутри группы рёбер этого цвета нет, и каждая группа красится $c - 1$ цветом.

    [Официальный разбор](https://codeforces.com/blog/entry/96072)
