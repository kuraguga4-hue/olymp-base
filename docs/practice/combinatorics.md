## Подсказки

??? question "1. 1326C · Разбиения перестановки"

    ??? tip "Подсказка 1"
        Какое наибольшее значение может иметь разбиение и какие числа в него обязаны попасть?

    ??? tip "Подсказка 2"
        Максимальное значение равно $(n-k+1)+\ldots+n$, и каждый отрезок должен содержать ровно одно из чисел $n-k+1,\ldots,n$. Пусть $a_1<\ldots<a_k$ их позиции.

    ??? tip "Подсказка 3"
        Между соседними позициями $a_i$ и $a_{i+1}$ нужно поставить ровно одну границу отрезков, что можно сделать $a_{i+1}-a_i$ способами.

    ??? tip "Подсказка 4"
        Ответ равен $\prod_{i=1}^{k-1}(a_{i+1}-a_i)$ по модулю, считается за $O(n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/74961)

??? question "2. 1879C · Чередуй!"

    ??? tip "Подсказка 1"
        На какие блоки естественно разбить строку и сколько символов оставляет самая длинная чередующаяся строка из каждого блока?

    ??? tip "Подсказка 2"
        Чтобы получить чередующуюся строку минимальным числом операций, из каждого блока одинаковых символов нужно оставить ровно один, значит минимум операций равен $n-k$, где $k$ число блоков.

    ??? tip "Подсказка 3"
        Сколькими способами выбрать, какой символ оставить? В блоке длины $len_i$ это $len_i$ способов, всего $\prod len_i$.

    ??? tip "Подсказка 4"
        Удаляемые символы можно удалять в любом порядке: это $(n-k)!$ перестановок. Ответ $\prod_{i=1}^{k} len_i\cdot (n-k)!$ по модулю, считается за $O(n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/120773)

??? question "3. 1391C · Циклические перестановки"

    ??? tip "Подсказка 1"
        Каких перестановок проще посчитать количество: циклических или нет?

    ??? tip "Подсказка 2"
        Посчитай нециклические и вычти из $n!$. Что получится, если у какого-то $i$ есть рёбра с обеих сторон?

    ??? tip "Подсказка 3"
        Тогда возникает простой цикл длины 3. Значит, в нециклической перестановке может быть только один пик, элемент $n$: она сначала возрастает до $n$, потом убывает.

    ??? tip "Подсказка 4"
        Любую такую перестановку можно получить, добавляя числа $n,n-1,\ldots,1$ в дек: для каждого числа, кроме $n$, есть выбор — в начало или в конец, то есть $2^{n-1}$ способов. Ответ $n!-2^{n-1}$ по модулю за $O(n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/81265)

??? question "4. 1475E · Рекламное агентство"

    ??? tip "Подсказка 1"
        Каких блогеров выгодно нанимать, чтобы сумма подписчиков была наибольшей?

    ??? tip "Подсказка 2"
        Нанимать нужно блогеров с наибольшим числом подписчиков: отсортируй их и бери префикс из $k$ лучших.

    ??? tip "Подсказка 3"
        Пусть $x$ минимальное число подписчиков среди нанятых. Всех, у кого подписчиков больше $x$, нанять обязательно, пусть их $m$. Сколькими способами добрать недостающих?

    ??? tip "Подсказка 4"
        Нужно выбрать $k-m$ блогеров из $cnt[x]$ с ровно $x$ подписчиками, то есть $\binom{cnt[x]}{k-m}$. Биномиальный коэффициент считай через факториалы и обратные элементы по модулю или по треугольнику Паскаля.

    [Официальный разбор](https://codeforces.com/blog/entry/87188)

??? question "5. 2086D · Четная строка"

    ??? tip "Подсказка 1"
        Что можно сказать о позициях, на которых стоят одинаковые буквы в подходящей строке?

    ??? tip "Подсказка 2"
        Все одинаковые буквы стоят одновременно либо на чётных, либо на нечётных позициях. Значит, строка определяется подмножеством букв на нечётных позициях и способом расставить буквы при этом подмножестве.

    ??? tip "Подсказка 3"
        Число подмножеств букв с суммарным количеством $odd = \lceil S/2 \rceil$ считается как в задаче о рюкзаке: $dp[i]$ — число способов набрать $i$ букв.

    ??? tip "Подсказка 4"
        Для фиксированного подмножества число строк — произведение мультиномиальных коэффициентов, равное $\frac{odd! \cdot even!}{\prod c_i!}$ и не зависящее от подмножества. Ответ — это значение, умноженное на $dp[odd]$, за $O(S \cdot 26)$.

    [Официальный разбор](https://codeforces.com/blog/entry/141425)

??? question "6. 2262C · Путешествие по миру"

    ??? tip "Подсказка 1"
        Если у каждого элемента есть только одно возможное ребро в следующий, к какой структуре это приводит и что значит «хорошая» перестановка?

    ??? tip "Подсказка 2"
        Каждая вершина имеет не больше одного исходящего ребра $v\to s-v$, где $s$ — максимум на суффиксе. Перестановка хорошая, если есть путь по всем вершинам.

    ??? tip "Подсказка 3"
        Докажи, что у хорошей перестановки ровно $2$ суффиксных максимума: это $M=a_n$ и последний элемент $b_n$. Ещё $0$ должен стоять раньше $M$, и путь заканчивается на $0\to M$.

    ??? tip "Подсказка 4"
        Обратный путь строится так: $M,\ 0,\ M-x,\ x,\ M-2x,\ 2x,\dots$ при $x=M-b_n$. Значения $0,x,\dots,(k-1)x$ стоят до $M$, остальные после, $k=\lfloor n/2\rfloor$, внутри групп порядок любой.

    ??? tip "Подсказка 5"
        Подходят только $x=M-a_{n-1}$ и $x=M-a_{n-2}$. Для каждого кандидата сгенерируй значения $0,x,\dots,(k-1)x$ и $M,M-x,\dots,M-(n-k-1)x$, отсортируй и сравни с $a$. Если совпало, добавь $k!\,(n-k-2)!$ перестановок.

    [Официальный разбор](https://codeforces.com/blog/entry/156688)

??? question "7. 1548C · Три поросенка"

    ??? tip "Подсказка 1"
        Что нужно посчитать для фиксированного $x$ по всем $i$ от 1 до $N$, и в какой сумме биномиальных коэффициентов это выражается?

    ??? tip "Подсказка 2"
        Попробуй ввести динамику $dp[x][m]$ — сумму $C(3i+m, x)$ по $i$ от 0 до $N-1$ для остатка $m$ от 0 до 2. Через неё выражается ответ?

    ??? tip "Подсказка 3"
        Сумма $dp[x][0]+dp[x][1]+dp[x][2]$ — это сумма $C(i,x)$ по $i$ от 0 до $3N-1$. Какое тождество сворачивает такую сумму?

    ??? tip "Подсказка 4"
        Тождество хоккейной клюшки даёт сумму равной $C(3N, x+1)$. Какие ещё соотношения между $dp[x][m]$ даёт тождество Паскаля?

    ??? tip "Подсказка 5"
        Паскаль даёт $dp[x][1]=dp[x][0]+dp[x-1][0]$ и $dp[x][2]=dp[x][1]+dp[x-1][1]$. Вместе с суммой это система из трёх уравнений на три неизвестных.

    ??? tip "Подсказка 6"
        База: $dp[0][0]=dp[0][1]=dp[0][2]=N$. Решай систему для каждого $x$ по очереди, ответ равен $dp[x][0]+C(3N,x)$. С предпосчётом факториалов всё работает за $O(N)$ (альтернатива — многочлен как геометрическая прогрессия и деление многочленов).

    [Официальный разбор](https://codeforces.com/blog/entry/93586)

??? question "8. 1667E · Центроидные вероятности"

    ??? tip "Подсказка 1"
        Как формулируется условие «вершина — центроид» через размеры поддеревьев при корне в вершине 1?

    ??? tip "Подсказка 2"
        Родитель вершины $i$ меньше $i$. Центроид — наибольшая вершина, у которой размер поддерева хотя бы $S=(n+1)/2$. Как найти $dp_i$ — число деревьев, где поддерево $i$ имеет размер хотя бы $S$?

    ??? tip "Подсказка 3"
        Для $2 <= i <= S$ раскрась поддерево $i$ без неё самой в красный цвет, остальные вершины (кроме 1 и $i$) в синий. Сколько существует таких раскрасок для размера $j+1$?

    ??? tip "Подсказка 4"
        Раскрасок $C(n-i, j)$. Для $k$-й по счёту красной или синей вершины родитель выбирается $k$ способами, для $i$ — $i-1$ способами. Получается формула суммы по $j$.

    ??? tip "Подсказка 5"
        Ответ для вершины $i$: $ans_i = dp_i - sum(ans_j / i)$ по $j>i$, так как центроид $j$ внутри поддерева $i$ учитывается с вероятностью $1/i$. Это даёт $O(n^2)$.

    ??? tip "Подсказка 6"
        Формулу для $dp_i$ можно упростить до суммы $(n-j-2)!/(n-i-j)!$ с постоянным множителем и постоянной разностью аргументов $i-2$. Это свёртка с развёрнутым массивом, считается NTT.

    ??? tip "Подсказка 7"
        Сумму для $ans_i$ считай за линию через суффиксные суммы. Итого $O(n log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/102013)
