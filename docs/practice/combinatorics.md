## Подсказки

??? question "1. 2125C · Подсчет хороших чисел"

    ??? tip "Подсказка 1"
        Какие простые числа определяют, хорошее число или нет?

    ??? tip "Подсказка 2"
        Число хорошее, если оно не делится на $2,3,5,7$. Считай количество на префиксе и вычитай префиксы. Используй включения-исключения по четырём простым с $\lfloor k/d\rfloor$ для произведений, $O(2^4)$ на запрос; либо периодичность с периодом $210$.

    [Официальный разбор](https://codeforces.com/blog/entry/144998)

??? question "2. 2144C · Неубывающие массивы"

    ??? tip "Подсказка 1"
        Можно ли сначала привести пары к виду $a_i\le b_i$, не изменив ответ?

    ??? tip "Подсказка 2"
        Да: если хоть одно хорошее подмножество существует, то можно считать $a_i\le b_i$, так что поменяй местами элементы в парах, где $a_i>b_i$.

    ??? tip "Подсказка 3"
        Для соседних индексов бывают два случая: $b_i\le a_{i+1}$ (никаких ограничений) или $b_i>a_{i+1}$, тогда $i$ и $i+1$ нужно менять местами вместе.

    ??? tip "Подсказка 4"
        Индексы объединяются в группы, которые решаются независимо, ответ $2^{n-k}$, где $k$ число индексов $i$ с $b_i>a_{i+1}$ (после обмена) по модулю.

    [Официальный разбор](https://codeforces.com/blog/entry/146474)

??? question "3. 1288C · Два массива"

    ??? tip "Подсказка 1"
        Нельзя ли записать оба массива одной неубывающей последовательностью?

    ??? tip "Подсказка 2"
        Рассмотри последовательность $a_1,\ldots,a_m,b_m,\ldots,b_1$: она неубывающая длины $2m$ со значениями от $1$ до $n$.

    ??? tip "Подсказка 3"
        Нужно посчитать число таких последовательностей. Какая это формула сочетаний?

    ??? tip "Подсказка 4"
        Это сочетания с повторениями из $n$ по $2m$, ответ $C_{n+2m-1}^{2m}=\frac{(n+2m-1)!}{(2m)!(n-1)!}$ по модулю.

    [Официальный разбор](https://codeforces.com/blog/entry/73105)

??? question "4. 2184D · Нечестная игра"

    ??? tip "Подсказка 1"
        Как оптимально ходит Алиса и что при этом происходит с двоичной записью?

    ??? tip "Подсказка 2"
        Чётное число делит на $2$, нечётному вычитает $1$. Тогда число действий равно $maxBit(a)+cntBit(a)$.

    ??? tip "Подсказка 3"
        Надо посчитать $a\le n=2^d$ с $maxBit+cntBit>k$: переберите $maxBit$ и $cntBit$, при фиксированном старшем бите вариантов $\binom{maxBit}{cntBit-1}$.

    ??? tip "Подсказка 4"
        Число $n=2^d$ проверь отдельно ($maxBit=d$, $cntBit=1$); биномиальные коэффициенты предпосчитай через $\binom nk=\binom{n-1}{k-1}+\binom{n-1}k$.

    [Официальный разбор](https://codeforces.com/blog/entry/150033)

??? question "5. 2249B · Разрезание перестановки"

    ??? tip "Подсказка 1"
        Каждое $s_i$ равно минимуму из двух максимумов — префиксного и суффиксного. А где в перестановке находится $n$ относительно разных $i$?

    ??? tip "Подсказка 2"
        Раскрой минимум на два случая: $s_i$ равно максимуму префикса или максимуму суффикса. Позиции первого типа не могут стоять правее позиций второго типа, иначе $n$ должно быть и левее, и правее.

    ??? tip "Подсказка 3"
        Поэтому позиции, где $s_i$ — максимум префикса, образуют префикс с возрастающими значениями, а где максимум суффикса — суффикс с убывающими значениями. Для каждой точки раздела проверь это.

    ??? tip "Подсказка 4"
        Затем иди по отсортированным значениям слева направо: если $s_i$ встретилось впервые, пропусти его, иначе умножь ответ на $s_i-i+1$. Сумма по всем допустимым разделам даёт ответ.

    [Официальный разбор](https://codeforces.com/blog/entry/155516)

??? question "6. 2200G · Операция Перестановка"

    ??? tip "Подсказка 1"
        Как свести вычитание и деление к сложению и умножению, и чей вклад в ответ считать?

    ??? tip "Подсказка 2"
        Замени $-$ на $+(-y)$ и $/y$ на умножение на $1/y$ по модулю; считай вклад каждой операции $+y$ как $y$ на ожидаемое произведение операций $x$ после неё.

    ??? tip "Подсказка 3"
        Если всего $m$ операций $x$, то число $x$-операций после данной равно любому $k$ от $0$ до $m$ с вероятностью $\frac1{m+1}$.

    ??? tip "Подсказка 4"
        Ожидание произведения случайных $k$ из $m$ множителей равно $\frac{dp[m][k]}{\binom mk}$, где $dp[i][j]=dp[i-1][j]+b_i\cdot dp[i-1][j-1]$ — сумма произведений подмножеств размера $j$.

    ??? tip "Подсказка 5"
        Итог: $S=\frac1{m+1}\sum_k\frac{dp[m][k]}{\binom mk}$, вклад каждого $+y$ равен $S\cdot y$, плюс вклад $x$ равен $x\cdot dp[m][m]$; время $O(n^2)$.

    [Официальный разбор](https://codeforces.com/blog/entry/151625)

??? question "7. 1251F · Красно-белый забор"

    ??? tip "Подсказка 1"
        Чему равен периметр забора и от каких параметров он зависит?

    ??? tip "Подсказка 2"
        Периметр равен $2(m+l_j)$, где $m$ — число досок, $l_j$ — длина красной доски. Сколько белых досок нужно для заданного периметра $P$ и красной доски длины $L$?

    ??? tip "Подсказка 3"
        Нужно ровно $P/2-L-1$ белых досок короче $L$. Переберём красную доску и для каждого запроса посчитаем число способов. Как посчитать для одной длины, если все белые доски разной длины?

    ??? tip "Подсказка 4"
        Для уникальной длины есть три варианта: не брать, поставить слева, поставить справа. А для длины, которая встречается хотя бы дважды, сколько вариантов?

    ??? tip "Подсказка 5"
        Для повторяющихся длин (их $m$) получается $C(2m, k)$ способов выбрать $k$ досок. Для $n$ уникальных получается $C(n,k)*2^k$.

    ??? tip "Подсказка 6"
        Общее число способов с $k$ белыми досками — свёртка, сумма по $i$ от $C(2m, k-i)*C(n,i)*2^i$. Перемножь два многочлена через NTT (модуль подходит).

    ??? tip "Подсказка 7"
        Для каждой красной доски отвечай на запросы чтением нужного коэффициента; в расчёте участвуют только белые доски короче $L$.

    [Официальный разбор](https://codeforces.com/blog/entry/70860)

??? question "8. 1667E · Центроидные вероятности"

    ??? tip "Подсказка 1"
        Как формулируется условие «вершина — центроид» через размеры поддеревьев при корне в вершине 1?

    ??? tip "Подсказка 2"
        Родитель вершины $i$ меньше $i$. Центроид — наибольшая вершина, у которой размер поддерева хотя бы $S=(n+1)/2$. Как найти $dp_i$ — число деревьев, где поддерево $i$ имеет размер хотя бы $S$?

    ??? tip "Подсказка 3"
        Для $2 <= i <= S$ раскрась поддерево $i$ без неё самой в красный цвет, остальные вершины (кроме 1 и $i$) в синий. Сколько существует таких раскрасок для размера $j+1$?

    ??? tip "Подсказка 4"
        Раскрасок $C(n-i, j)$. Для $k$-й по счёту красной или синей вершины родитель выбирается $k$ способами, для $i$ — $i-1$ способами. Получается формула суммы по $j$.

    ??? tip "Подсказка 5"
        Ответ для вершины $i$: $ans_i = dp_i - sum(ans_j / i)$ по $j>i$, так как центроид $j$ внутри поддерева $i$ учитывается с вероятностью $1/i$. Это даёт $O(n^2)$.

    ??? tip "Подсказка 6"
        Формулу для $dp_i$ можно упростить до суммы $(n-j-2)!/(n-i-j)!$ с постоянным множителем и постоянной разностью аргументов $i-2$. Это свёртка с развёрнутым массивом, считается NTT.

    ??? tip "Подсказка 7"
        Сумму для $ans_i$ считай за линию через суффиксные суммы. Итого $O(n log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/102013)
