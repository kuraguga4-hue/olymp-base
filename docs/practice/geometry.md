## Подсказки

??? question "1. 1354C1 · Просто вписываем многоугольник"

    ??? tip "Подсказка 1"
        Как выглядит $2n$-угольник при чётном $n$ и как его удобнее всего повернуть относительно квадрата?

    ??? tip "Подсказка 2"
        Нужно повернуть его так, чтобы некоторые стороны стали параллельны сторонам квадрата.

    ??? tip "Подсказка 3"
        Тогда сторона квадрата равна удвоенному расстоянию от центра до стороны многоугольника, то есть $1/\tan(\pi/(2n))$.

    [Официальный разбор](https://codeforces.com/blog/entry/77593)

??? question "2. 659D · Велосипедная гонка"

    ??? tip "Подсказка 1"
        С какой стороны от Марии находится вода и при каком повороте она может в неё упасть?

    ??? tip "Подсказка 2"
        Вода всегда справа, поэтому упасть можно только при левом повороте. Занумеруй направления (север 0, запад 1, юг 2, восток 3): поворот налево, если новое направление равно старому плюс 1 по модулю 4.

    ??? tip "Подсказка 3"
        Считай такие повороты за $O(n)$. Альтернатива через сумму углов: $x\cdot270+(n-x)\cdot90=180(n-2)$, и ответ зависит только от $n$.

    [Официальный разбор](https://codeforces.com/blog/entry/44093)

??? question "3. 908C · Новый год и керлинг"

    ??? tip "Подсказка 1"
        Какие из ранее положенных дисков может коснуться новый диск?

    ??? tip "Подсказка 2"
        Те, у которых разность $x$-координат не больше $2r$. Для каждого такого диска найди по теореме Пифагора разность высот: гипотенуза равна $2r$, катет — разность по $x$.

    ??? tip "Подсказка 3"
        Итоговая координата $y$ — максимум по всем таким случаям, всего $O(n^2)$.

    [Официальный разбор](https://codeforces.com/blog/entry/56713)

??? question "4. 1096C · Многоугольник для угла"

    ??? tip "Подсказка 1"
        Какие углы вообще возможны в правильном $n$-угольнике?

    ??? tip "Подсказка 2"
        Все вписанные углы вида $180k/n$, где $1\le k\le n-2$. Нужно решить $180k=ang\cdot n$; пусть $g=\gcd(180,ang)$, тогда $n$ делится на $180/g$.

    ??? tip "Подсказка 3"
        Решение $n=x\cdot 180/g$, $k=x\cdot ang/g$; берёшь $x=1$, кроме случая $k=n-1$, где $x=2$.

    [Официальный разбор](https://codeforces.com/blog/entry/64156)

??? question "5. 1451D · Игра в круге"

    ??? tip "Подсказка 1"
        Как второй игрок может отвечать на ход первого, чтобы сохранять какую-то симметрию?

    ??? tip "Подсказка 2"
        Если первый идёт вверх, второй идёт вправо и наоборот, так фишка после его хода оказывается на прямой $x=y$. Пусть $z$ — максимальное целое, при котором точка $(kz,kz)$ в круге.

    ??? tip "Подсказка 3"
        Если точка $(kz,k(z+1))$ тоже внутри круга, выигрывает первый игрок, иначе второй.

    [Официальный разбор](https://codeforces.com/blog/entry/84885)

??? question "6. 1354C2 · Не так просто вписываем многоугольник"

    ??? tip "Подсказка 1"
        Как удобно расположить $2n$-угольник относительно квадрата и что будет, если его вращать?

    ??? tip "Подсказка 2"
        Положи нижнюю сторону горизонтально и вращай вокруг центра. Достаточно повернуть не более чем на $\pi/(2n)$, так как дальше всё симметрично с обменом $x$ и $y$.

    ??? tip "Подсказка 3"
        При повороте разность по $x$ убывает, а по $y$ растёт, ответ — максимум из двух, и его можно искать тернарным поиском по углу.

    ??? tip "Подсказка 4"
        Из симметрии оптимален поворот на $\pi/(4n)$.

    ??? tip "Подсказка 5"
        Тогда ответ равен $\cos(\pi/(4n))/\sin(\pi/(2n))$.

    [Официальный разбор](https://codeforces.com/blog/entry/77593)
