## Подсказки

??? question "1. 1807D · Нечётные запросы"

    ??? tip "Подсказка 1"
        Что именно меняется в сумме массива после запроса, а что остаётся прежним?

    ??? tip "Подсказка 2"
        Сумма нового массива равна сумме префикса до $l-1$, плюс $(r-l+1)\cdot k$, плюс сумма суффикса после $r$. Префиксы и суффиксы посчитай заранее, и каждый запрос проверяется за $O(1)$ на чётность суммы, всего $O(n+q)$.

    [Официальный разбор](https://codeforces.com/blog/entry/114143)

??? question "2. 1469B · Красные и синие"

    ??? tip "Подсказка 1"
        Какие суммы вообще могут быть префиксными суммами итоговой последовательности?

    ??? tip "Подсказка 2"
        Любая префиксная сумма равна сумме префикса $r$ плюс сумме префикса $b$, поэтому ответ не больше $\max p_i+\max q_j$, и эта граница достижима. Сначала ставишь нужный префикс $r$, потом нужный префикс $b$, остальное как угодно; итого $O(n+m)$.

    [Официальный разбор](https://codeforces.com/blog/entry/86082)

??? question "3. 1690D · Черно-белая полоса"

    ??? tip "Подсказка 1"
        Что нужно сделать с отрезком длины $k$, чтобы он весь стал чёрным?

    ??? tip "Подсказка 2"
        Нужно перекрасить все белые клетки отрезка. Переберёшь все отрезки длины $k$, число белых клеток на каждом берёшь из префиксных сумм, ответ — минимум.

    [Официальный разбор](https://codeforces.com/blog/entry/103658)

??? question "4. 2276C · Подотрезки"

    ??? tip "Подсказка 1"
        Как выразить сумму подотрезка через два значения префиксных сумм, и что значит делимость на $k$ для этих двух значений?

    ??? tip "Подсказка 2"
        Строй префиксные суммы по модулю $k$: подотрезок подходит, если остатки в позициях $i$ и $j$ равны и $j-i>k$. Считай такие пары двумя указателями с массивом $cnt$ остатков за $O(n)$ (или бинпоиском за $O(n \log n)$).

    [Официальный разбор](https://codeforces.com/blog/entry/157752)

??? question "5. 1915E · Романтические стаканы"

    ??? tip "Подсказка 1"
        Как переписать равенство сумм на нечётных и чётных позициях в виде одной суммы со знаками?

    ??? tip "Подсказка 2"
        Смени знак у элементов на чётных индексах: тогда нужно найти подотрезок с нулевой суммой.

    ??? tip "Подсказка 3"
        Подотрезок с суммой $0$ существует тогда и только тогда, когда среди префиксных сумм есть две равные.

    ??? tip "Подсказка 4"
        Проверь наличие двух равных префиксных сумм сортировкой или хеш-таблицей (осторожно со взломами), итого $O(n)$ или $O(n\log n)$.

    [Официальный разбор](https://codeforces.com/blog/entry/123952)

??? question "6. ABC480D · Concatenation of Prefixes"

    ??? tip "Подсказка 1"
        Если научиться быстро считать сумму первых $i$ элементов $B$, как ответить на запрос $[L, R]$?

    ??? tip "Подсказка 2"
        Ответ — $T_R - T_{L-1}$, где $T_i$ — сумма первых $i$ элементов $B$. Первые $i$ элементов $B$ — это несколько целых блоков $(A_1, \dots, A_k)$ и начало следующего блока. Сумма целого блока $k$ — префиксная сумма $S_k$ массива $A$.

    ??? tip "Подсказка 3"
        Число целых блоков — наибольшее $k$ с $k(k+1)/2 \le i$, его найди бинпоиском. Тогда $T_i = (S_1 + \dots + S_k) + S_m$, где $m = i - k(k+1)/2$. Предподсчитай префиксные суммы $S$ и префиксные суммы от $S$. Итого $O(N + Q \log N)$.

    [Официальный разбор](https://atcoder.jp/contests/abc480/editorial/27257)

??? question "7. 2258B2 · Нарезка моркови (сложная версия)"

    ??? tip "Подсказка 1"
        В каком порядке выгодно делать разрезы для фиксированного целевого значения $x$?

    ??? tip "Подсказка 2"
        Для $x$ разрезы выгодно делать в порядке $x \cdot 2^k, x \cdot 2^{k-1}, \ldots, x$. Тогда $a_i=2^k x$ даёт вклад $2^k$, иначе вклад равен $\min(\frac{a_i}{x}, 2^k-1)$.

    ??? tip "Подсказка 3"
        Оптимальный $x$ не больше $\frac{m}{2^k}$ (если меньше 1, то он равен 1, и ответ — сумма длин морковок). Ни одно $i$ не вносит больше $2^k$.

    ??? tip "Подсказка 4"
        С помощью префиксных сумм для каждого $x$ найди, сколько элементов дают вклад $y$; решение работает за $O(n+m \log m)$.

    [Официальный разбор](https://codeforces.com/blog/entry/156316)

??? question "8. 1343D · Одинаковая палиндромная сумма"

    ??? tip "Подсказка 1"
        Что будет, если зафиксировать итоговую сумму $x$ в каждой паре $a_i$ и $a_{n-i+1}$: сколько у пары может быть случаев?

    ??? tip "Подсказка 2"
        У каждой пары три случая: менять ничего не надо, надо заменить один элемент или оба. Сколько пар попадает в первый случай для данного $x$, можно посчитать массивом частот.

    ??? tip "Подсказка 3"
        Для пары суммы, достижимые не более чем одной заменой, образуют отрезок $[\min(a_i, a_{n-i+1})+1; \max(a_i, a_{n-i+1})+k]$. Как быстро прибавить $1$ на отрезке сразу для всех пар?

    ??? tip "Подсказка 4"
        Прибавляй $+1$ в левой границе и $-1$ за правой, затем посчитай префиксные суммы: получишь $pref_x$ — число пар, которым хватит не более одной замены. Вместе с массивом частот $cnt_x$ ответ для $x$ равен $(pref_x - cnt_x) + (n/2 - pref_x) \cdot 2$, бери минимум по $x$ от $2$ до $2k$, всё за $O(n+k)$.

    [Официальный разбор](https://codeforces.com/blog/entry/76352)

??? question "9. 2230E · Минимальное влияние"

    ??? tip "Подсказка 1"
        Что можно сказать о вкладе новости, если она слабее порога пользователя по одному из параметров?

    ??? tip "Подсказка 2"
        Вклад $I_p(i,j)$ не превосходит $p_i$ и монотонен по $p_i$; для $I_c$ аналогично. Новости разбиваются на несколько простых случаев по положению $p_i$ и $c_i$ относительно порогов пользователя $j$.

    ??? tip "Подсказка 3"
        Если $p_i < tp_j$, то $I_p = 0$, и нужна новость с минимальным $c_i$. Если $c_i < tc_j$, нужна новость с минимальным $p_i$. Если $p_i \ge tp_j + d_j$, снова нужен минимальный $c_i$; если $c_i \ge tc_j + d_j$, нужен минимальный $p_i$.

    ??? tip "Подсказка 4"
        Для новостей внутри прямоугольника вклад равен $p_i + c_i$. Достаточно взять минимальную сумму $p_i + c_i$ по всем новостям: если она вне прямоугольника, то её настоящий вклад не больше, и ответ не хуже.

    ??? tip "Подсказка 5"
        Итого для пользователя нужны четыре минимума по условиям на $p_i$ и $c_i$ и один глобальный минимум суммы. Поскольку значения не больше $A = 10^6$, предпосчитай префиксные и суффиксные минимумы за $O(n + A)$ и отвечай за $O(1)$.

    [Официальный разбор](https://codeforces.com/blog/entry/153834)
