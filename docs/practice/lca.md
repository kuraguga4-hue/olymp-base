## Подсказки

??? question "1. 2187C · Джерри и Том"

    ??? tip "Подсказка 1"
        Какое ребро из текущей вершины выгодно выбирать каждому из игроков?

    ??? tip "Подсказка 2"
        Оба игрока всегда идут по исходящему ребру, ведущему как можно дальше. Соединив каждую вершину $u$ с самой дальней достижимой $a(u)$, получишь дерево с корнем $n$.

    ??? tip "Подсказка 3"
        Пусть $d(u)$ — глубина в этом дереве. Если $d(x) < d(y)$, Том не поймает Джерри до вершины $n$ и $f(x,y) = 0$.

    ??? tip "Подсказка 4"
        Иначе Том идёт в $\operatorname{lca}(x,y)$, где и ловит Джерри, и $f(x,y) = d(y) - d(\operatorname{lca}(x,y))$.

    ??? tip "Подсказка 5"
        Разбей искомую сумму на три. Сумма $\min(d(x), d(y))$ по парам считается сортировкой глубин; сумма $d(\operatorname{lca})$ — через размеры поддеревьев (пар с $\operatorname{lca} = u$ ровно $\frac{s(u)(s(u)-1)}{2} - \sum \frac{s(v)(s(v)-1)}{2}$ по сыновьям); третья сумма по парам с равной глубиной считается похожим образом, в эталонном решении — техникой DSU on tree (слияние меньшего к большему), итого $O(n \log^2 n)$.
