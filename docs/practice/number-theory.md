## Подсказки

??? question "1. 2234A · Евклид, последовательность, два числа"

    ??? tip "Подсказка 1"
        Как устроена последовательность остатков алгоритма Евклида по порядку величин?

    ??? tip "Подсказка 2"
        Она невозрастающая, поэтому подойти может только $b$, отсортированная по невозрастанию; отсортируй и проверь для каждого $i$ от $1$ до $k-2$, что $a_{i+2}=a_i\bmod a_{i+1}$.

    [Официальный разбор](https://codeforces.com/blog/entry/154319)

??? question "2. 1916B · Два делителя"

    ??? tip "Подсказка 1"
        Как устроено $x$ по отношению к $b$ в случаях, когда $a$ делит $b$ и когда не делит?

    ??? tip "Подсказка 2"
        Если $b$ кратно $a$, то $x = b \cdot b/a$. Иначе $x = b \cdot a / \gcd(a, b)$, то есть $x = \mathrm{LCM}(a, b)$.

    [Официальный разбор](https://codeforces.com/blog/entry/124138)

??? question "3. 2131C · Уравняй"

    ??? tip "Подсказка 1"
        Когда $x$ можно превратить в $y$ по модулю $k$?

    ??? tip "Подсказка 2"
        Это возможно тогда и только тогда, когда $x\equiv y\pmod k$ или $x+y\equiv0\pmod k$. Приведи каждый элемент обоих мультимножеств к $\min(x\bmod k,\;(k-x\bmod k)\bmod k)$ и проверь, что мультимножества совпадают.

    [Официальный разбор](https://codeforces.com/blog/entry/145439)

??? question "4. 2267C · GCD сокровищница"

    ??? tip "Подсказка 1"
        Чему может быть равен итоговый НОД и на что он обязан делиться?

    ??? tip "Подсказка 2"
        Итоговый НОД делит $x$ и все выбранные $a_i$. Для каждого делителя $d$ числа $x$ посчитай сумму всех $a_i$, кратных $d$ (кучки выгодно красть целиком), и возьми максимум по $d>1$.

    [Официальный разбор](https://codeforces.com/blog/entry/157126)

??? question "5. 2124C · Умножение подмножеств"

    ??? tip "Подсказка 1"
        Какое условие на $x$ получается из каждой пары соседних элементов?

    ??? tip "Подсказка 2"
        Каждое $a_i$ делит $b_i$, а $x$ должно быть кратно $b_i/\gcd(b_i,b_{i+1})$ для каждого $i<n$.

    ??? tip "Подсказка 3"
        Эти условия достаточны, поэтому ответ — НОК всех $b_i/\gcd(b_i,b_{i+1})$. Сложность $O(n\log a_i)$.

    [Официальный разбор](https://codeforces.com/blog/entry/144382)

??? question "6. 2126E · Н-О-Д, не повезло!"

    ??? tip "Подсказка 1"
        Какие условия делимости должны выполняться для префиксных и суффиксных НОД, и чему равен общий НОД?

    ??? tip "Подсказка 2"
        Нужны $p_i\mid p_{i-1}$, $s_i\mid s_{i+1}$ и $p_n=s_1=g$. Поделив всё на $g$, получаем $P_i$, $S_i$.

    ??? tip "Подсказка 3"
        На позиции $i$ с $x=p_{i-1}/p_i$ (при $i\ge2$) и $y=s_{i+1}/s_i$ (при $i\le n-1$) нужно $\gcd(x,S_i)=1$ и $\gcd(y,P_i)=1$; тогда $a_i=g\cdot P_i\cdot S_i$ подходит. Проверь все позиции, $O(n\log V)$.

    [Официальный разбор](https://codeforces.com/blog/entry/144845)

??? question "7. 2236F1 · Выборы в Саранске (простая версия)"

    ??? tip "Подсказка 1"
        Когда $\text{lcm}$ чисел равен их произведению?

    ??? tip "Подсказка 2"
        Тогда числа попарно взаимно просты, то есть каждое простое делит не более одного $p_i$.

    ??? tip "Подсказка 3"
        Для фиксированного простого: либо оно не используется, либо выбирается один индекс $i$ и степень от $1$ до $v(a_i)$. Способов $1+\sum v(a_i)$.

    ??? tip "Подсказка 4"
        Разные простые независимы, поэтому ответ — произведение этих величин по всем простым, делящим какое-нибудь $a_i$.

    [Официальный разбор](https://codeforces.com/blog/entry/154496)

??? question "8. 1845F · Пловцы в бассейне"

    ??? tip "Подсказка 1"
        Когда два пловца вообще могут встретиться, и как это зависит от того, плывут они в одну сторону или навстречу?

    ??? tip "Подсказка 2"
        Для пары пловцов моменты встреч повторяются с периодом $\frac{2l}{|v_i - v_j|}$ (в одну сторону) или $\frac{2l}{v_i + v_j}$ (навстречу). Значит, всё определяется числами $w = |v_i \pm v_j|$, и какие из них возможны?

    ??? tip "Подсказка 3"
        Все возможные значения $w \le 2V$ находятся двумя быстрыми умножениями многочленов: одно для сумм $v_i + v_j$, другое для разностей $v_i - v_j$. Как по ним посчитать число различных моментов встреч до времени $T$?

    ??? tip "Подсказка 4"
        Для фиксированного $w_i$ моменты встречи имеют вид $\frac{2l \cdot k}{w_i}$ для $k$ от $1$ до $k_i$. Одна и та же дробь $\frac{k}{w_i}$ может возникнуть и для другого $w_j$, поэтому считай только несократимые дроби.

    ??? tip "Подсказка 5"
        Перебирай $w_i$ в порядке убывания. Количество несократимых дробей $\frac{k}{w_i}$ при $1 \le k \le k_i$ равно $\sum_{d | w_i} \mu(d) \lfloor \frac{k_i}{d} \rfloor$ (функция Мёбиуса).

    ??? tip "Подсказка 6"
        Сократимые дроби не теряем, а «передаём» меньшему знаменателю: для каждого делителя $d$ числа $w_i$ в $w_j = \frac{w_i}{d}$ записываем $k_j = \lfloor \frac{k_i}{d} \rfloor$.

    ??? tip "Подсказка 7"
        Итого: FFT для множества $w$ и проход по $w \le 2V$ с делителями за $O(V \log V)$, общая сложность $O(n + V \log V)$.

    [Официальный разбор](https://codeforces.com/blog/entry/117791)
