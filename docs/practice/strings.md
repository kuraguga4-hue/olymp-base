## Подсказки

??? question "1. 1137B · Расписание смены"

    ??? tip "Подсказка 1"
        Что делать, если ни одного вхождения $t$ в перестановку $s$ получить нельзя?

    ??? tip "Подсказка 2"
        Почему можно считать, что в оптимальном ответе строка начинается с $t$? Что будет, если символы до первого вхождения перенести в конец?

    ??? tip "Подсказка 3"
        Следующее вхождение $t$ хочется получить как можно левее, то есть наложить его на предыдущее. Какую характеристику строки $t$ для этого нужно знать?

    ??? tip "Подсказка 4"
        Нужен наибольший суффикс $t$, совпадающий с префиксом $t$ (префикс-функция, z-функция или хеши). Выпиши $t$, затем повторяй только оставшуюся после наложения часть, пока хватает символов, а остаток выведи в конце.

    [Официальный разбор](https://codeforces.com/blog/entry/65825)

??? question "2. 1326D2 · Префиксно-суффиксный палиндром (усложненная версия)"

    ??? tip "Подсказка 1"
        Какую часть ответа можно взять «бесплатно», сопоставляя символы с начала и с конца строки одновременно?

    ??? tip "Подсказка 2"
        Найди максимальное $k$, при котором $s_1=s_n$, $s_2=s_{n-1}$, ..., $s_k=s_{n-k+1}$. Почему в оптимальном ответе $\min(l,r)=k$?

    ??? tip "Подсказка 3"
        Останется найти самый длинный палиндром, являющийся префиксом или суффиксом средней части $s[(k+1)..(n-k)]$. Как найти самый длинный палиндромный префикс строки $a$ с помощью префикс-функции?

    ??? tip "Подсказка 4"
        Посчитай префикс-функцию строки $a+\#+\overline{a}$, где $\overline{a}$ — разворот $a$: последнее значение $p$ даёт длину самого длинного палиндромного префикса. Сделай то же для $\overline{a}$ (палиндромный суффикс), выбери больший и собери ответ $s[1..k]+w+s[(n-k+1)..n]$ за $O(|s|)$.

    [Официальный разбор](https://codeforces.com/blog/entry/74961)

??? question "3. 1902E · Коллапс строк"

    ??? tip "Подсказка 1"
        Если развернуть первую строку, как выразить длину коллапса через общий префикс двух строк?

    ??? tip "Подсказка 2"
        Длина коллапса равна $|a|+|b|-2|LCP(a',b)|$, где $a'$ — развёрнутая $a$. Как тогда выглядит сумма по всем парам?

    ??? tip "Подсказка 3"
        Ответ равен $2n\sum|s_i|-2\sum_i\sum_j LCP(s_i',s_j)$. Нужна структура, считающая сумму LCP строки со всеми строками набора.

    ??? tip "Подсказка 4"
        Построй бор на развёрнутых строках и для каждой вершины храни число строк, проходящих через неё. Для строки $s_j$ спускайся по бору и суммируй эти числа по всем вершинам, кроме корня. Итого $O(S\cdot A)$ или $O(S\log A)$, где $S$ — суммарная длина.

    [Официальный разбор](https://codeforces.com/blog/entry/122951)

??? question "4. 1200E · Склеивание слов"

    ??? tip "Подсказка 1"
        Что нужно знать про текущую склеенную строку и следующее слово, чтобы присоединить его?

    ??? tip "Подсказка 2"
        Нужно найти наибольшее совпадение суффикса уже собранной строки с префиксом нового слова. Какой длины часть собранной строки достаточно рассматривать?

    ??? tip "Подсказка 3"
        Для слова длины $y$ достаточно взять только последние $y$ символов собранной строки, иначе перекрытие всё равно не будет длиннее $y$. Какую строку составить, чтобы найти нужное перекрытие за линейное время?

    ??? tip "Подсказка 4"
        Построй строку $c=W_{k+1}+F(k)[x-y..x]$ и посчитай для неё префикс-функцию (KMP).

    ??? tip "Подсказка 5"
        Последнее значение префикс-функции, меньшее $y$, равно длине наибольшего перекрытия $L$. Допиши к ответу $W_{k+1}[L+1..y]$. Случай, когда собранная строка короче слова, разбирается так же, но берётся начало слова длиной $x$. Для каждого слова работа линейна, итого $O(\text{суммарная длина слов})$.

    [Официальный разбор](https://codeforces.com/blog/entry/69035)

??? question "5. 2209E · Тривиальная задача на строки"

    ??? tip "Подсказка 1"
        Что можно сказать о строке, которую нельзя разбить дальше, и как это связано с её границами (строка, которая одновременно префикс и суффикс)?

    ??? tip "Подсказка 2"
        Подумай про кратчайшую границу строки: сама ли она имеет границы? Докажи от противного, что у неё границ нет.

    ??? tip "Подсказка 3"
        Оптимальное разбиение префикса на части единственно, и все части в нём — строки без границ.

    ??? tip "Подсказка 4"
        Получить его можно так: пока у строки есть граница, отрезай кратчайшую границу; когда границ не осталось, оставшаяся строка — последняя часть.

    ??? tip "Подсказка 5"
        Посчитай $\pi$-массив (префикс-функцию) и по нему для каждого префикса длину кратчайшей границы $b_i$: если $\pi_i=0$, то $b_i=0$; если $\pi_{\pi_i}=0$, то $b_i=\pi_i$; иначе $b_i=b_{\pi_i}$.

    ??? tip "Подсказка 6"
        Тогда $dp_i=1$ при $b_i=0$, иначе $dp_i=dp_{i-b_i}+1$. Каждый запрос решается независимо за $O(n)$, всего $O(nq)$.

    [Официальный разбор](https://codeforces.com/blog/entry/152272)

??? question "6. 2023C · Ч+К+С"

    ??? tip "Подсказка 1"
        Что можно сказать о раскраске сильносвязного графа, в котором длины всех циклов кратны $k$?

    ??? tip "Подсказка 2"
        Такой граф можно покрасить в $k$ цветов так, что каждое ребро идёт из цвета $c$ в цвет $(c+1) \bmod k$. Какие новые рёбра можно добавлять, не ломая это свойство?

    ??? tip "Подсказка 3"
        Добавлять можно только рёбра, сохраняющие этот инвариант цветов. Для фиксированных покрасок заведи массивы счётчиков по цвету и классу вершин и сравни их по этому критерию.

    ??? tip "Подсказка 4"
        Но второй граф можно покрасить по-другому, например, прибавив ко всем цветам $1$ по модулю $k$. Как тогда изменятся массивы?

    ??? tip "Подсказка 5"
        Массивы второго графа сдвигаются по циклу на произвольную величину, значит, нужно проверить, является ли один массив циклическим сдвигом другого.

    ??? tip "Подсказка 6"
        Это делается алгоритмом Кнута-Морриса-Пратта.

    [Официальный разбор](https://codeforces.com/blog/entry/135341)

??? question "7. 2144F · Группы скобок"

    ??? tip "Подсказка 1"
        Какая короткая подстрока обязательно есть в любой правильной скобочной последовательности? Когда из-за этого ответ точно $-1$?

    ??? tip "Подсказка 2"
        Если «()» не задана, ответ не больше $2$. Какие две правильные скобочные последовательности (ПСП) подойдут, если учесть, что в оставшихся строках скобки чередуются?

    ??? tip "Подсказка 3"
        Одна из них — «()()…()», вторая — «((…(())…))»: любую заданную строку с двумя одинаковыми скобками подряд можно отнести к первой, остальные — ко второй.

    ??? tip "Подсказка 4"
        Значит, надо лишь проверить, можно ли поместить все строки в одну группу, то есть построить ПСП, не содержащую ни одну из заданных строк как подстроку.

    ??? tip "Подсказка 5"
        Построй динамику $dp[i][bal][v]$: можно ли составить скобочную последовательность длины $i$ с балансом $bal$ и неотрицательным балансом на префиксах, где $v$ — вершина бора, соответствующая самому длинному суффиксу, лежащему в боре.

    ??? tip "Подсказка 6"
        Переходы по скобке считаются автоматом Ахо-Корасик. Вершина небезопасна, если она терминальная или из неё по суффиксным ссылкам можно дойти до терминальной (это считается одним обходом дерева ссылок), в небезопасные вершины переходить нельзя.

    ??? tip "Подсказка 7"
        Асимптотика: $O(nk)$ на построение автомата и $O(nk^3)$ на динамику.

    [Официальный разбор](https://codeforces.com/blog/entry/146474)
