## Подсказки

??? question "1. 1873A · Короткая сортировка"

    ??? tip "Подсказка 1"
        Сколько всего различных входных строк возможно?

    ??? tip "Подсказка 2"
        Строк всего 6, поэтому ответ NO только для «bca» и «cab», иначе YES; либо проверь, что не более двух букв стоят не на своих местах.

    [Официальный разбор](https://codeforces.com/blog/entry/120634)

??? question "2. 732A · Куплю лопату"

    ??? tip "Подсказка 1"
        Насколько большим может понадобиться число лопат $x$, если смотреть только на последнюю цифру $k\cdot x$?

    ??? tip "Подсказка 2"
        Достаточно перебрать $x$ от 1 до 10: при $x=10$ остаток $k\cdot x \bmod 10$ равен нулю; выведи первое $x$, при котором остаток равен 0 или $r$.

    [Официальный разбор](https://codeforces.com/blog/entry/47890)

??? question "3. 2230B · Цифровая строка"

    ??? tip "Подсказка 1"
        Какие подпоследовательности из цифр без четвёрки делятся на 4 по признаку делимости, и что это говорит о порядке чётных и нечётных цифр?

    ??? tip "Подсказка 2"
        После удаления цифр 4 делятся только 12 и 32, поэтому чётная цифра не должна идти после нечётной. Переберь границу: слева бери только чётные, справа только нечётные, считая их префиксными и суффиксными счётчиками за $O(n)$, и выбери максимум.

    [Официальный разбор](https://codeforces.com/blog/entry/153834)

??? question "4. 2184C · Огромная куча"

    ??? tip "Подсказка 1"
        Сколько различных значений встречается на одном уровне дерева, где из $x$ идут рёбра в $\lfloor \frac{x}{2} \rfloor$ и $\lceil \frac{x}{2} \rceil$?

    ??? tip "Подсказка 2"
        На каждом слое не более двух различных чисел, слоёв $O(\log n)$. Ищи минимальную глубину, на которой встречается $k$, перебором слоёв или рекурсией с мемоизацией.

    [Официальный разбор](https://codeforces.com/blog/entry/150033)

??? question "5. 2194C · Шифровка"

    ??? tip "Подсказка 1"
        Каким может быть значение информативности относительно $n$?

    ??? tip "Подсказка 2"
        Перебирай делитель $d$ числа $n$ и проверяй, можно ли получить строку с информативностью $d$.

    ??? tip "Подсказка 3"
        Для каждого $i\le d$ проверь, что у позиций $i,i+d,i+2d,\dots$ есть общая буква: храни для позиции массив из $26$ флагов и перебирай букву. Итого $O(26\cdot n\cdot d(n))$.

    [Официальный разбор](https://codeforces.com/blog/entry/150940)

??? question "6. 1971F · Периметр круга"

    ??? tip "Подсказка 1"
        Достаточно ли считать точки только в одной четверти плоскости?

    ??? tip "Подсказка 2"
        Да, по симметрии считай $x\ge0,y>0$ и умножай на 4. Перебирать нужно только точки, расстояние от которых до начала лежит в $[r, r+1)$.

    ??? tip "Подсказка 3"
        Для каждого $x$ от 0 до $r$ держи переменную height, уменьшая её, пока расстояние до $(x,height)$ не станет меньше $r+1$, затем перебирай $y$ вниз, пока расстояние не станет меньше $r$.

    ??? tip "Подсказка 4"
        Площадь кольца равна $2\pi r-\pi$, поэтому всего посещается $O(r)$ точек на тест.

    [Официальный разбор](https://codeforces.com/blog/entry/129364)

??? question "7. 1335E2 · Палиндром из трех блоков (сложная версия)"

    ??? tip "Подсказка 1"
        Палиндром из трёх блоков устроен как $a$ раз число $x$, потом $b$ раз число $y$, потом $a$ раз число $x$. Что можно зафиксировать, чтобы остальное считалось просто?

    ??? tip "Подсказка 2"
        Если для числа $c$ ты берёшь $k$ вхождений в первый блок и столько же в третий, какие именно вхождения выгодно взять?

    ??? tip "Подсказка 3"
        Выгодно брать первые $k$ и последние $k$ вхождений $c$. Как тогда выглядит отрезок, из которого берётся средний блок, и сколько всего различных пар (число, $k$) надо рассмотреть?

    ??? tip "Подсказка 4"
        Для каждого числа $c$ с позициями вхождений $pos_c$ перебирай $k$ только по левой половине. Тогда средний отрезок $[pos_c[k-1]+1,\ pos_c[cnt-k]-1]$, в нём найди максимальное количество одного значения среди $AL=200$ вариантов и обнови ответ значением $2k+cntin$. Всего $O(n)$ отрезков, итого $O(n \cdot AL)$.

    [Официальный разбор](https://codeforces.com/blog/entry/75993)

??? question "8. 2091G · Глеб и гребля"

    ??? tip "Подсказка 1"
        Что произойдёт, если перебирать текущую силу $t$ от $k$ до 1 и для каждой искать достижимые позиции поиском в ширину?

    ??? tip "Подсказка 2"
        Такой перебор работает за $O(s \cdot k)$, это слишком долго. Что можно сказать про ответ, если $s$ очень велико по сравнению с $k$?

    ??? tip "Подсказка 3"
        При $k \ge 3$ и $s \ge k^2$ ответ равен $k$ или $k-2$: ответ $k$ проверяется простым делением, иначе выводим $k-2$.

    ??? tip "Подсказка 4"
        Остаётся случай $s \le k^2$. Как ограничить число значений $t$, которые придётся перебирать, если останавливать перебор при достижении точки $s$?

    ??? tip "Подсказка 5"
        Ответ не меньше примерно $\sqrt{s}-3$, поэтому перебор идёт по $O(k-ans)$ значениям силы, каждое за $O(s)$.

    ??? tip "Подсказка 6"
        Итоговое время не больше $(k-\sqrt{s})\cdot s \le \frac{4k^3}{27}$, этого достаточно для прохождения тестов.

    [Официальный разбор](https://codeforces.com/blog/entry/141047)
