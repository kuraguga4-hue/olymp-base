# Теория

Каждая статья начинается с задачи, которую тема делает простой, и проверена олимпиадником.

| [Бинарный поиск и поиск по ответу](binary-search.md) | новичок | k принтеров, i-й печатает страницу за tᵢ секунд; за какое минимальное время они вместе напечатают n страниц (n, tᵢ ≤ 10⁹)? Ответ бывает до 10¹⁸ секунд — перебирать время по секунде нельзя, бинпоиск по ответу — около 60 проверок «успеем ли за T», каждая — один проход по принтерам. |
