# Теория

Каждая статья начинается с задачи, которую тема делает простой, и проверена олимпиадником.

| Тема | Уровень | Зачем |
|---|---|---|
| [Префиксные суммы](prefix-sums.md) | новичок | 10⁵ запросов «сумма на отрезке [l, r]» в массиве из 10⁵ чисел: в лоб — 10¹⁰ операций, с префиксными суммами — каждый запрос за O(1). |
| [Бинарный поиск и поиск по ответу](binary-search.md) | новичок | За какое минимальное время k принтеров с разной скоростью напечатают n страниц? Перебирать время бесконечно, бинпоиск по ответу — около 60 проверок. |
| [Два указателя](two-pointers.md) | новичок | Самый длинный отрезок массива из положительных чисел с суммой не больше S: в лоб O(n²), двумя указателями — один проход. |
| [Жадные алгоритмы и как их доказывать](greedy.md) | новичок | Из заявок на аудиторию выбрать максимум непересекающихся: брать ту, что раньше всех заканчивается, — и доказать обменом, почему это оптимально. |
| [Динамическое программирование: начало](dp-intro.md) | средний | Сколькими способами подняться на n ступенек шагами 1 и 2: рекурсия умирает уже на n = 50, ДП считает n = 10⁶ мгновенно. |
| [Графы: обход в ширину и в глубину](bfs-dfs.md) | средний | Минимальное число ходов конём из одной клетки доски 8×8 в другую — BFS находит и число, и сам путь. |
| [Теория чисел: НОД, решето, быстрое возведение в степень](number-theory.md) | средний | Посчитать aᵇ mod m при b = 10¹⁸: в лоб — никогда, быстрым возведением в степень — около 60 шагов. |
| [Система непересекающихся множеств (DSU)](dsu.md) | средний | Между городами строятся дороги, и после каждой нужно отвечать, связаны ли два города: DSU отвечает почти мгновенно. |
