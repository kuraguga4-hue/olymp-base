# Команде: что происходит и что делать сейчас

## Что происходит
- Делаем открытую базу для подготовки к олимпиадам по программированию: **статьи (Теория) + подборки задач (Практика) + вход по хендлу Codeforces со статистикой**.
- Побеждаем качеством: **8 отличных статей, каждая проверена олимпиадником**, лучше 30 средних.
- Код и черновики пишут агенты Claude. Люди решают, что делать, проверяют и исправляют.
- Работаем до 17:30, обед 13:00–14:00 — по очереди, чтобы работа не вставала. Защита в 18:00.

## Что нужно на каждом ноутбуке (10 минут)
1. **VPN включён** — без него Claude из России не работает. Проверка: открывается claude.ai.
2. **Git** (git-scm.com) и **Python 3.12** (python.org; на Windows при установке поставить галочку «Add python.exe to PATH») — если ещё нет.
3. **VS Code** (code.visualstudio.com).
4. В VS Code: слева «Extensions» → найти **Claude Code** (издатель Anthropic) → Install → войти в наш общий аккаунт Claude.
5. **Аккаунт GitHub** — у каждого свой. Ник отправить Ярославу: он добавит тебя в репозиторий. Придёт письмо от GitHub — принять приглашение.
6. Когда Ярослав пришлёт ссылку на репозиторий: в VS Code `Ctrl+Shift+P` → «Git: Clone» → вставить ссылку → выбрать папку → «Open». Репозиторий приватный: VS Code попросит войти в GitHub — войти.
7. В VS Code: Terminal → New Terminal, вставить и нажать Enter (на Mac вместо `python` — `python3`):

```
python -m pip install mkdocs-material requests
```

8. Открыть панель Claude Code (значок Claude) — это твой агент. Первое сообщение ему:

```
Проверь, что git настроен и я могу делать push в этот репозиторий. Если нет — настрой или скажи, что сделать мне.
```

При первом push может открыться окно входа в GitHub — войти.

## Какие сервисы Claude и зачем

| Сервис | Для чего | Кто |
|---|---|---|
| **Claude Code в VS Code** | всё, что в репозитории: статьи, подборки, сайт, проверки, коммиты | все четверо |
| **claude.ai → Проект «Олимпиадная база»** | разговор без файлов: обсудить статью, подобрать «красивую задачу», текст питча. В знания проекта загружены `docs/CONTEXT.md`, `docs/STYLE.md`, `docs/assets/topics.json` | все: аккаунт общий, проект виден всем |

**Не используем:** Claude Code в браузере (облачный) — у него ограничен интернет, Codeforces может не открыться, и он работает через отдельные ветки; agent teams и субагентов — аккаунт один, лимит общий.

Если наш аккаунт — ключ API, а не подписка: в Claude Code входить через «Anthropic Console», а проекта в claude.ai не будет — общий контекст тогда только в репозитории (`docs/CONTEXT.md`).

## Общие правила
- Одна задача — одна новая сессия агента; закончил — `/clear`.
- Агенту не пишем «сделай платформу». Пишем, что сделать и как проверить. Готовые промты — `START.md`, раздел 4.
- Агент ошибся (выдумал задачу, неверный код, вода) — строка в `docs/INCIDENTS.md`.
- Перед push агент запускает проверки. Красное — не пушим.
- Застрял на 15 минут — сказать вслух команде.
- Чат команды — только «запушил: …», «блок: …, нужен …» и ссылки. Остальное голосом.
