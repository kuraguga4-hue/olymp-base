    Подсказки¶

    1. 1676H2 · Максимизация пересечений (сложная версия)
    Подсказка 1

    Какие пары \((i, j)\) нужно посчитать, чтобы получить ответ, и как они выражаются через сравнение элементов массива?

    Подсказка 2

    Нужно посчитать число пар \((i, j)\), где \(i < j\) и \(a_i \ge a_j\). Эта задача родственна подсчёту инверсий. Как считать такие пары, добавляя элементы по одному слева направо?

    Подсказка 3

    Идя по \(j\) от 1 до \(n\), для каждого \(a_j\) посчитай, сколько уже добавленных значений не меньше \(a_j\), а затем добавь \(a_j\) в структуру.

    Подсказка 4

    Для подсчёта используй дерево отрезков или дерево Фенвика (BIT) по значениям; альтернатива — модификация сортировки слиянием. Асимптотика \(O(n \log n)\).

    2. 2057D · Заказ мерча
    Подсказка 1

    Где в оптимальном отрезке должны стоять максимум и минимум?

    Подсказка 2

    Они стоят на краях: иначе отрезок можно сузить, и ответ только улучшится. Остаётся два случая: минимум слева, максимум справа, и наоборот.

    Подсказка 3

    Значение отрезка при минимуме слева равно \((a_r-r)-(a_l-l)\), то есть разделяется на часть от \(r\) и часть от \(l\).

    Подсказка 4

    В каждой вершине дерева отрезков храни максимум и минимум по \(a_i-i\) и ответ. Ответ вершины — максимум из ответов детей и (максимум в правом сыне минус минимум в левом).

    Подсказка 5

    Аналогично для второго случая. Обновление точечное, поэтому каждый запрос обрабатывается за \(O(\log n)\).

    3. 2249C · Блочный круг
    Подсказка 1

    Как свести циклические префиксы перестановки к обычным отрезкам?

    Подсказка 2

    Продублируй перестановку в массив \(q\): префиксы, читаемые с позиции \(l\), — это \([l,l], [l,l+1], \ldots, [l,l+n-1]\). Двигай правый конец \(r\) слева направо; при добавлении \(q_r\) затрагиваются лишь начальные позиции \(l \in [L,U]\), где \(L=\max(1,r-n+1)\), \(U=\min(r,n)\).

    Подсказка 3

    Число блоков меняется на \(1 - [x-1 \in S] - [x+1 \in S]\), где \(x = q_r\): плюс один, ноль или минус один. Значение \(v\) входит в \([l, r-1]\) ровно когда \(last_v \ge l\).

    Подсказка 4

    Для каждой начальной позиции храни текущее число блоков в дереве отрезков с ленивым добавлением на отрезке и глобальным максимумом. Для \(x\) добавь \(1\) на \([L,U]\), затем вычти \(1\) на \([L,\min(U,last_{x-1})]\) и на \([L,\min(U,last_{x+1})]\), после чего положи \(last_x = r\).

    Подсказка 5

    Позиция со значением больше \(2\) уже не может стать хорошей, поэтому удали её, заменив значение очень маленьким числом. Пока максимум больше \(2\), удаляй; каждая позиция удаляется один раз. Ответ — число оставшихся позиций, сложность \(O(n\log n)\).

    4. 2262B · Игра на выбывание
    Подсказка 1

    Что изменится, если рассматривать удаления в обратном порядке?

    Подсказка 2

    Обратные удаления становятся вставками. Поддерживай множество \(S\) индексов противников, которым чемпион проигрывает (сдаётся).

    Подсказка 3

    При вставке чемпиона в позицию \(i\) найди наибольший \(j < i\) из \(S\). Сумма сил активных воинов от \(j\) до \(i-1\) — это сила чемпиона при встрече с \(i\). Если она меньше \(a_i\), добавь \(i\) в \(S\) и положи \(j = i\).

    Подсказка 4

    После этого сила чемпиона выросла, поэтому проверь и элементы множества правее \(i\): снова сравнивай сумму от \(j\) до \(i-1\) с \(a_i\).

    Подсказка 5

    Суммы на отрезке и добавления элементов обрабатывай деревом Фенвика или деревом отрезков.

    5. 2145E · Прогнозирование популярности
    Подсказка 1

    Для каждого зрителя можно ли заранее посчитать минимальную популярность, при которой фильм ему подходит?

    Подсказка 2

    Эта величина равна \(p_i=\max(a_i-ac,0)+\max(d_i-dr,0)\).

    Подсказка 3

    Популярность \(p\) достижима, если для каждого \(i\le p\) есть хотя бы \(i\) зрителей с \(p_i<i\). Значит, нужно найти наименьшее \(p\), для которого количество зрителей с \(p_i<p\) меньше \(p\).

    Подсказка 4

    Храни в дереве отрезков массив \(cnt_p-p\). Добавление зрителя — прибавление \(1\) на отрезке для всех \(p>p_i\), удаление — прибавление \(-1\).

    Подсказка 5

    Ответ — самое левое отрицательное значение. Найди его спуском по дереву, храня минимум на отрезке. Итого \(O((n+q)\log n)\).

    6. 2149G · Buratsuta 3
    Подсказка 1

    Сколько значений могут занимать в отрезке больше трети его длины?

    Подсказка 2

    Таких значений не больше двух, поэтому для каждого отрезка достаточно держать двух кандидатов.

    Подсказка 3

    В каждой вершине дерева отрезков храни до двух кандидатов со счётчиками и объединяй их как в алгоритме Мисры–Гриса: совпало — прибавь, есть свободный слот — положи, иначе вычти счётчики.

    Подсказка 4

    Для каждого значения заранее сохрани отсортированный список позиций. Точное число вхождений кандидата на отрезке находится двумя бинарными поисками.

    Подсказка 5

    Ответ на запрос: возьми двух кандидатов из дерева, проверь каждого по спискам позиций и выведи подходящих по возрастанию (или \(-1\)). Один запрос работает за \(O(\log n)\).

    7. 2146E · Ещё одна задача про MEX
    Подсказка 1

    Нужно ли на самом деле считать mex, чтобы получить правильный ответ?

    Подсказка 2

    Можно ослабить условие: для каждого \(x\), которого нет в массиве, считай число элементов, больших \(x\). Максимум всё равно достигается на mex.

    Подсказка 3

    Для каждого \(x\) от \(0\) до \(n\) достаточно рассмотреть отрезок, начинающийся сразу после последнего вхождения \(x\) перед правым концом \(r\).

    Подсказка 4

    Двигай \(r\) вправо и храни в дереве отрезков значения \(b_x\). При добавлении \(a_r\) обнули \(b_{a_r}\) и прибавь \(1\) на \(b_i\) для \(0\le i<a_r\).

    Подсказка 5

    Ответ после каждого \(r\) — максимум массива \(b\). Всего получается \(O(n\log n)\).

    8. 2126G2 · Большие выигрыши! (сложная версия)
    Подсказка 1

    Что будет, если зафиксировать минимум \(mn\) и пытаться поднимать медиану как можно выше?

    Подсказка 2

    Для кандидата в медианы \(M\) замени элементы на \(+1\), если \(a_i\ge M\), и на \(-1\) иначе. Медиана подотрезка не меньше \(M\), когда сумма знаков на нём неотрицательна (так в условии ниже).

    Подсказка 3

    Для позиции \(u\) с \(a_u=mn\) найди границы \(l_u\), \(r_u\) монотонным стеком. Условие: максимальный суффикс на \([l_u,u-1]\) плюс знак \(u\) плюс максимальный префикс на \([u+1,r_u]\) не меньше нуля.

    Подсказка 4

    Дерево отрезков хранит в узле сумму, лучший префикс, лучший суффикс и ответ; оно отвечает на такие запросы за \(O(\log n)\).

    Подсказка 5

    Двигай \(mn\) вверх и поднимай \(med\), пока условие выполняется для всех \(u\) с \(a_u=mn\). При росте \(med\) переводи позиции со значением меньше \(med\) в \(-1\) точечными обновлениями. Ответ — максимум \(med-mn\), всего \(O(n\log n)\).

    Подсказки: Спортивная тренировка
    Подсказка 1

    Какие уже рассмотренные школьники могут образовать допустимую пару с очередным, если перебирать номера по возрастанию? Достаточно ли помнить самого левого и самого правого из них?

    Подсказка 2

    Получается строка над \(\{L, R, M\}\). Для \(t=1\) по ней считается ДП из трёх чисел \((f, dp_L, dp_R)\) с простыми переходами.

    Подсказка 3

    Каждый символ — матрица \(3\times3\) в (max,+)-алгебре. Храни строку в дереве отрезков по номерам. При добавлении с края меняются только префиксные или суффиксные минимумы — держи их в монотонных деках.

    Подсказка 4

    Для \(t=2\) замени матрицы автоматом из 20 состояний: в вершине дерева храни переходы «состояние → (новое состояние, прибавка к ответу)».
