    Подсказки¶

    1. 954I · И снова равные строки
    Подсказка 1

    Как по двум строкам одинаковой длины найти минимальное число операций «заменить все вхождения одной буквы на другую»?

    Подсказка 2

    Построй граф на буквах, где ребро показывает, что на одной позиции стоят две разные буквы. Что тогда нужно сделать в каждой компоненте?

    Подсказка 3

    В каждой компоненте все буквы превращаются в одну, поэтому расстояние равно числу различных букв минус число компонент. Остаётся узнать рёбра для каждой подстроки \(S\).

    Подсказка 4

    Для пары букв \(a\), \(b\) как найти все сдвиги, где в \(S\) стоит \(a\) напротив \(b\) в \(T\)?

    Подсказка 5

    Поставь единицы в позиции \(S\) с буквой \(a\) и в позиции \(T\) с буквой \(b\) и вычисли свёртку через FFT. Так для каждой пары букв узнаёшь, в каких подстроках нужно объединить \(a\) и \(b\).

    Подсказка 6

    Для каждой подстроки собери рёбра по всем парам букв и посчитай компоненты обходом в глубину или любым другим методом.

    2. 993E · Никита и порядковая статистика
    Подсказка 1

    Как свести задачу к подсчёту для каждого префикса, сколько в нём чисел меньше \(x\)?

    Подсказка 2

    Пусть \(s[i]\) — число элементов меньше \(x\) на префиксе длины \(i\). Подотрезок содержит ровно \(d\) таких элементов, когда разность каких величин равна \(d\)?

    Подсказка 3

    Посчитай \(r[i]\) — сколько раз значение \(i\) встречается среди \(s\). Тогда ответ для \(d\) — сумма \(r[i]*r[j]\) по парам с \(i-j=d\). Как превратить разность индексов в сумму?

    Подсказка 4

    Разверни массив: \(v[i]=r[n-i]\). Тогда коэффициент произведения \(r\) и \(v\) при \(n+d\) равен искомому ответу для \(d\).

    Подсказка 5

    Перемножь многочлены через FFT аккуратно (значения до \(10^{10}\)) или через NTT по двум модулям с китайской теоремой об остатках. Случай \(k=0\) считай отдельно. Итого \(O(n log n)\).

    Официальный разбор

    3. 1096G · Счастливые билеты
    Подсказка 1

    Как посчитать количество последовательностей длины \(n/2\) из разрешённых цифр с заданной суммой, и почему ответ — сумма квадратов этих количеств?

    Подсказка 2

    Наивная динамика \(dp[x][y]\) слишком медленная. Как записать переход от длины \(x\) к \(x+1\) на языке многочленов?

    Подсказка 3

    Рассмотри многочлен \(f(x)\), где коэффициент при \(x^i\) равен 1, если цифра \(i\) разрешена. Чему равны коэффициенты \(f(x)\) в степени \(a\)?

    Подсказка 4

    Осталось возвести \(f\) в степень \(n/2\) и просуммировать квадраты коэффициентов. Это можно сделать бинарным возведением в степень с NTT-умножением.

    Подсказка 5

    Либо один раз применить NTT к \(f\) (считая её многочленом степени \(5n\)), возвести каждое полученное значение в степень \(n/2\) и сделать обратное преобразование. Разбор даёт для обоих способов \(O(n \log n)\).

    Официальный разбор

    4. 1398G · Соревнования по бегу
    Подсказка 1

    Какую форму может иметь круг (замкнутый маршрут) в такой трассе?

    Подсказка 2

    Круг — всегда прямоугольник между двумя вертикальными отрезками \(i\) и \(j\). Чему равен его периметр?

    Подсказка 3

    Периметр равен \(2(a_i - a_j + y)\). Значит, нужно найти все значения разностей \(a_i - a_j\). Почему наивный перебор пар слишком медленный?

    Подсказка 4

    Перепиши разность как сумму: возьми \(b_j = K - a_j\) для достаточно большого \(K\), тогда \(a_i - a_j = a_i + b_j - K\).

    Подсказка 5

    Построй многочлены с \(x^{a_i}\) и \(x^{b_j}\) и перемножь. Ненулевые коэффициенты показывают все достижимые суммы.

    Подсказка 6

    Умножение делается FFT (или алгоритмом Карацубы). Так получаешь множество возможных длин кругов.

    Подсказка 7

    Для запроса \(l\) проверь все делители \(l\): ответ строится по возможным длинам кругов (перебор делителей).

    5. 827E · Ржавая строка
    Подсказка 1

    Когда число \(k\) может быть периодом строки с неизвестными символами «?», которые можно заполнить как угодно?

    Подсказка 2

    Назови пару позиций \(i\), \(j\) противоречащей, если там стоят разные известные символы. Как с такими парами связан период?

    Подсказка 3

    Период \(k\) допустим тогда и только тогда, когда нет противоречащей пары с \(|i-j|\), делящимся на \(k\). Почему так (можно построить заполнение пропусков по остаткам)?

    Подсказка 4

    Достаточно найти все расстояния \(x\), для которых есть противоречащая пара. Как свести поиск таких расстояний к суммам элементов двух множеств позиций?

    Подсказка 5

    Расстояния получаются как суммы элементов двух множеств (одно отражено). Это произведение многочленов с коэффициентами 0 и 1, оно считается FFT за \(O(n log n)\).

    Подсказка 6

    После этого для каждого \(k\) проверь все числа вида \(i*k <= n\) на наличие плохого расстояния. Суммарно по всем \(k\) всё решение работает за \(O(n log n)\).

    6. 2201E · Счетчик ABBA
    Подсказка 1

    Как связаны между собой первая и вторая половины строки, которую можно разложить на \(A+B+B+A\)?

    Подсказка 2

    Строка раскладывается так тогда и только тогда, когда первая половина — циклический сдвиг второй. Для фиксированного сдвига \(k\) посчитай число совпавших '?' без конфликта 'a' с 'b': получится \(2^x\) подходящих вторых половин.

    Подсказка 3

    Просто сложить по всем сдвигам нельзя: строка с периодом посчитается несколько раз, как «abaababaabaa» при \(k=0\) и \(k=3\). Нужно считать по минимальному периоду первой половины.

    Подсказка 4

    Для каждого делителя \(d\) числа \(n/2\) сожми обе половины в строки длины \(d\) и посчитай то же по всем сдвигам. Строки с минимальным периодом \(d\) учтутся ровно один раз, но в \(xd\) они учтутся \(x\) раз.

    Подсказка 5

    Исправь это по делителям: для \(d_1 \mid d_2\) вычитай из ответа для \(d_2\) величину \((d_2/d_1)\) раз ответ для \(d_1\). Сумма полученных значений по делителям и есть ответ.

    Подсказка 6

    Для одного \(d\) разверни вторую половину и посчитай циклическую свёртку с первой по FFT за \(d \log d\). Всего \(O(n \log n \log \log n)\) плюс \(O(n)\) на каждый делитель.
